## 2. 계획과 달랐던 것

### 2-1. `wss:`를 빠뜨렸다가 되돌렸다

정책초안 §1은 dev `connect-src`에 `ws: wss:`인데 구현이 `ws:`만 넣었다.
교차검증에서 잡아 고쳤다. https dev·프록시 뒤 HMR에서 위반이 뜬다.

### 2-2. matcher에 **경계가 없었다**

`(?!course-assets|_next/static|…)` 형태라 접두사만 같아도 제외됐다 —
`/apitest`·`/course-assets-x`가 CSP를 못 받았다. 각 항목 뒤에 `/`와 확장자
`$`를 붙여 고쳤다.

**두 번 고쳤다.** 첫 수정에서 `favicon\.ico$`로 적었는데, JS 문자열 리터럴이라
백슬래시 한 개는 유효하지 않은 이스케이프로 풀려 `.`이 임의 문자가 됐다
(`/faviconXico`가 여전히 제외됨). 문자열에 두 개로 적어야 정규식에 마침표
리터럴이 간다. **12개 경로로 실측해 확인했다.**

### 2-3. `x-nonce` 주석이 사실과 달랐다

*"Next가 nonce를 붙이려면 이 요청 헤더를 읽어야 한다"* 고 적었는데 **틀렸다.**
Next는 **응답에 건 CSP 헤더를 직접 파싱**한다
(`next/dist/server/app-render/app-render.js`). `src/`에서 `x-nonce`를 읽는 코드는
0건이다. 헤더 자체는 관례로 남기되 주석을 사실대로 고쳤다.

> 이게 왜 중요한가 — 이 오해를 믿고 "응답 CSP 헤더는 빼도 되겠지"라고 판단하면
> **nonce가 통째로 사라진다.**

### 2-4. env 가드를 추가했다

`supabaseOrigin()`이 `new URL(process.env...!)`로 throw할 수 있었다. 이 함수는
이제 `/admin`이 아니라 **모든 요청**에서 불리므로, env가 비면 proxy가 죽어
**사이트 전체가 500**이 된다. 공개 페이지는 Supabase 장애에도 정적 폴백으로
버티도록 만들어 뒀는데 CSP가 그 설계를 무너뜨릴 뻔했다.

## 3. 강제 전환을 막는 것 — **정적 페이지에 nonce가 없다**

`'strict-dynamic'`이 켜지면 `'self'`가 무시되고 nonce 있는 스크립트만 돈다.
그런데 프리렌더된 HTML에는 nonce가 없다. 실측:

| 라우트 | script | nonce |
|---|---|---|
| `/education/programs` (동적) | 25 | **27** ✅ |
| **`/admin/login`** (정적) | 13 | **0** ❌ |

**지금 강제로 바꾸면 관리자 로그인이 완전히 막힌다.** 해결 방향은
[docs/07-dev/14](../../07-dev/14-CSP-정책과-적용.md) §5.

## 4. 곁다리로 정리한 중복

새 탭 링크 패턴이 **네 곳에 복사**돼 있었다(요약 카드·자료 블록·모바일 바·
포트폴리오 상세). 넷 다 `target="_blank"` + `rel="noopener noreferrer"` +
sr-only 안내 + 아이콘 모션을 각자 적고 있었다 — 하나만 빠뜨려도 알아채기 어렵다.

`NewTabLink` 하나로 묶었다. `icon`은 **엘리먼트가 아니라 컴포넌트 타입**으로
받는다 — 엘리먼트로 받으면 호출부가 모션 클래스를 다시 적게 되고(실제로 처음엔
그랬다) 모션 스펙이 갈라진다.
