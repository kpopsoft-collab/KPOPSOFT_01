# 05 — 검증체크리스트

**화면이 "접수되었습니다"를 띄우는 건 증거가 아니다.**
WP 258의 신고 스크린샷이 정확히 그 화면이었다 — 성공 화면은 저장 성공만 뜻한다.
아래는 전부 **메일함과 로그에서** 확인한다.

## A. 발송 (D2)

- [ ] 홈 Contact에서 실제 제출 → **`kpopsoft@gmail.com`에 알림 도착**
- [ ] `/education` 하단 교육 문의 폼도 같은 형식으로 도착
      (두 폼이 같은 Server Action을 쓴다 — [02](02-현황분석.md) §6)
- [ ] 발신자가 **`inquiry@kpopsoft.com`**이다 (설계 §7)
- [ ] 제목에 문의 유형과 신청자 이름이 들어 있다 (설계 §7)
- [ ] **HTML 본문과 텍스트 대체본이 둘 다 있다** (설계 §7)
- [ ] 본문에 유형·보낸 사람·연락처·접수 시각·문의 내용이 다 있다
- [ ] **어드민 상세 링크**(`/admin/inquiries/<id>`)가 있고 눌러서 열린다
      (`docs/06-admin/03…:47` 요구사항. 지금 `renderBody`에는 없다)
- [ ] 선택 항목(예상 일정·예산)이 본문 끝 블록에 붙어 온다
- [ ] **메일에서 답장을 누르면 문의자 주소가 잡힌다** (`reply_to`)
- [ ] 연락처가 이메일이 아니면 `reply_to`가 **안 붙는다** (설계 §7)

## B. 수신 (D6)

- [ ] 외부 계정에서 `inquiry@kpopsoft.com`으로 메일 발송
- [ ] `kpopsoft@gmail.com`으로 **전달되어 도착**
- [ ] Cloudflare Email Routing에서 해당 건이 처리된 것으로 보인다

## C. 배달 품질 — 스팸함으로 가지 않는가

- [ ] Gmail **받은편지함**에 온다. 스팸/프로모션 탭이 아니다
- [ ] Gmail "원본 보기"에서 **SPF·DKIM·DMARC 모두 `PASS`**
      (SPF는 이미 `_spf.mx.cloudflare.net` — [02](02-현황분석.md) §5)

## D. 저장은 여전히 성공하는가 (회귀 — D1)

메일을 고치다 저장을 깨면 훨씬 나쁘다.

- [ ] 제출 후 `/admin/inquiries` 목록에 새 건이 뜬다
- [ ] 상세에서 연락처·본문이 폼 입력대로 들어가 있다
- [ ] 이메일 + 연락처를 다 넣으면 `contact`가 `이메일 / 전화` 형식이다

## E. 실패해도 저장은 살아 있는가 (D5 핵심)

**일부러 고장 내서 확인한다.** 안 하면 D5를 검증한 게 아니다.

- [ ] `CLOUDFLARE_API_TOKEN`을 **틀린 값**으로 두고 제출
  - [ ] 화면은 여전히 **성공** (기준: `docs/06-admin/03…:47`)
  - [ ] 문의는 **DB에 저장됨**
  - [ ] 로그에 `[email] 문의 알림 미발송 — unauthorized (inquiry <id>)`
  - [ ] 그 id로 `/admin/inquiries`에서 해당 건을 찾을 수 있다
- [ ] 토큰을 **비우고** 제출 → `configuration_error`가 같은 형식으로 남는다
      (`console.info`로 조용히 넘어가지 않는다)
- [ ] `INQUIRY_NOTIFICATION_TO`를 비우면 `configuration_error`로 막힌다
      — `admin_users`로 조용히 폴백하지 **않는다**(D3)
- [ ] **`delivered`가 비고 `queued`만 있는 응답을 성공으로 처리하지 않는다**
      (설계 §7 상태 판정. 매핑 단위 테스트로 확인)

## F. 비밀값이 새지 않는가 (설계 §7)

- [ ] 토큰·계정 ID가 **로그에 안 찍힌다**
- [ ] 테스트 픽스처에 실제 토큰이 없다
- [ ] `.env.example`에 값이 아니라 **설명만** 있다
- [ ] OpenProject 댓글·백로그 문서에 토큰이 없다

## G. 스팸 방지 회귀

- [ ] honeypot(`company_website`)을 채우고 제출 → **저장도 발송도 안 됨.**
      화면은 성공 (`inquiry-actions.ts:83-85`)
- [ ] 이메일 형식이 틀리면 저장 전에 막힌다

## H. 빌드

- [ ] `npx tsc --noEmit` 통과
- [ ] `npm run build` 통과
- [ ] 이식한 테스트 2종 통과

      `vibedays-modal.tsx`)은 이 작업과 무관하다. 그 2건 **외에** 새 에러가
      없는지만 본다 (`docs/07-dev/02-개발상태.md`)
- [ ] `resend` 제거 후 잔여 import가 없다
