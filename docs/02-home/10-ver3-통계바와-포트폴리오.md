## SECTION 05. 포트폴리오

홈에서 가장 중요한 섹션입니다. ver2의 Selected Work를 **3분류 필터 구조**로 확장합니다.

#### Eyebrow

```text
SELECTED WORK
```

#### Title

```text
실제로 작동하는
제품과 도구를 만들었습니다.
```

#### Description

```text
고객의 아이디어와 업무 문제를
실제로 사용할 수 있는 서비스와 업무 도구로 구현했습니다.
```

#### 카테고리 필터

```text
전체 · 소프트웨어 · AI 솔루션 · 교육
```

- 기본 선택은 `전체`입니다.
- 필터는 클라이언트 사이드 전환이며 페이지 리로드가 없습니다.
- 해당 분류에 사례가 없으면 그 필터 버튼을 숨깁니다(빈 결과 화면을 노출하지 않습니다).
- 하나의 사례가 두 분류에 동시에 속할 수 있습니다(예: 소프트웨어 + AI 솔루션).

#### 이미지 원칙

**모든 카드는 실제 사례 이미지를 사용합니다.** 목업·스톡·추상 이미지를 쓰지 않습니다.

이미지는 카드 면적의 약 65~75%를 차지합니다.

- 웹서비스: 실제 전체 화면
- 앱: 디바이스 목업
- 관리자: 브라우저 대시보드
- AI 자동화: 입력 → 처리 → 결과
- 교육: 실제 교육 현장 또는 수강생 결과물

#### 레이아웃

ver2 유지 — 모든 카드를 같은 크기로 반복하지 않습니다.

```text
대표 프로젝트 대형 카드 1개
보조 프로젝트 카드 2개
가로형 프로젝트 카드 1개
```

카드 전체를 클릭할 수 있게 하고, 카드마다 `사례 보기` 버튼을 반복하지 않습니다.

#### 열린 항목 — 오픈프로젝트 연동

IA 주석: *"[오픈프로젝트] 연동 가능성 체크 — 포트폴리오 발행 누르면 자동으로 업데이트 될 수 있게"*

외부 오픈프로젝트에서 포트폴리오를 발행하면 홈 포트폴리오가 자동 갱신되는 구조입니다. **연동 가능 여부 확인 전까지는 구현하지 않습니다.** 현재는 Admin 수동 등록을 유지하되, 데이터 모델에 외부 출처 식별자를 넣을 수 있도록 여지를 남깁니다.
