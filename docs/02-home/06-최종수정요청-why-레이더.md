## 13. WHY KPOPSOFT — 인터랙티브 역량 구조도

### 섹션 라벨

> WHY KPOPSOFT

### 메인 제목

> 기술이 실제로 활용되기까지,  
> 필요한 역량을 연결합니다.

### 보조 문구

> 전략과 디자인, 소프트웨어와 AI, 교육까지 분리된 영역을 하나의 실행 과정으로 연결합니다.

### 시각화 기본 방향

기존의 일반적인 3개 카드형 레이아웃 대신, KPOPSOFT의 핵심 역량이 서로 연결되는 모습을 보여주는 5축 레이더 형태의 역량 구조도를 적용해주세요.

이 그래픽은 실제 측정값을 보여주는 데이터 차트가 아니라, KPOPSOFT의 역량이 서로 연결되고 확장되는 모습을 표현하는 브랜드 시각화입니다. 객관적인 근거가 없는 점수, 퍼센트, 순위, 수치형 눈금은 노출하지 마세요.

### 레이더 구조의 5개 축

#### 01. Strategy

> 아이디어와 비즈니스 목표를 구체적인 실행 방향으로 설계합니다.

#### 02. Design

> 사용자가 이해하고 편리하게 사용할 수 있는 서비스 경험을 설계합니다.

#### 03. Technology

> 아이디어를 안정적으로 작동하는 웹·앱 서비스와 업무 시스템으로 구현합니다.

#### 04. AI

> 기술 시연에 그치지 않고 실제 업무와 서비스에서 활용할 수 있는 AI 솔루션을 구축합니다.

#### 05. Education

> AI를 이해하는 데서 끝나지 않고 실제 업무에 활용할 수 있도록 실습 중심의 교육을 제공합니다.

### 레이더 중앙 메시지

> FROM IDEA  
> TO IMPACT

한글이 디자인에 더 적합한 경우 다음 문구를 사용할 수 있습니다.

> 아이디어에서  
> 실제 활용까지

### 컬러 방향

- Strategy: Blue 계열
- Design: Blue와 Red 사이의 기존 보조 컬러
- Technology: Blue
- AI: Red
- Education: Green

새로운 색상을 과도하게 추가하지 말고 기존 KPOPSOFT 컬러 시스템 안에서 구성해주세요.

### 섹션 진입 애니메이션

사용자가 WHY KPOPSOFT 섹션에 처음 진입하면 다음 순서로 애니메이션을 실행해주세요.

1. 레이더 축과 격자선이 fade-in
2. 각 축의 포인트가 중앙에서 바깥쪽으로 확장
3. 포인트를 연결하는 외곽선이 순차적으로 생성
4. 내부 면이 Blue, Red, Green 계열의 낮은 투명도 컬러로 채워짐
5. 각 역량 라벨이 순차적으로 표시됨

전체 진입 애니메이션은 약 1.2~1.6초로 설정해주세요. 최초 진입 시 한 번만 실행하고, 짧은 스크롤 이동마다 반복 재생되지 않게 해주세요.

### 기본 Idle 모션

진입 애니메이션이 끝난 후 각 포인트가 기본 위치에서 약 3~6% 범위로 천천히 움직이게 해주세요.

- 각 축의 움직임 시작 시점을 조금씩 다르게 설정
- 레이더 면이 부드럽게 확장되고 수축하도록 처리
- 약 4~6초 단위로 자연스럽게 반복
- 갑작스러운 변화나 튀는 easing 사용 금지
- 사용자가 콘텐츠를 읽는 데 방해되지 않을 정도로 미세하게 적용
- 섹션이 화면 밖으로 나가면 반복 애니메이션 일시 중지

이 움직임은 데이터 값의 변화를 의미하지 않고, 역량이 유기적으로 연결되고 발전한다는 브랜드 메시지를 표현합니다.

### Hover 및 Focus 인터랙션

각 역량 축에 마우스를 올리거나 키보드 포커스가 이동하면 다음 인터랙션을 적용해주세요.

- 선택된 포인트가 바깥쪽으로 약간 확장
- 선택된 축의 선, 포인트, 라벨 강조
- 해당 역량의 브랜드 컬러 강조
- 나머지 축과 라벨의 투명도 감소
- 레이더 면이 선택된 축 방향으로 부드럽게 변화
- 해당 역량 설명을 중앙 또는 차트 옆 정보 영역에 표시
- 마우스나 포커스가 벗어나면 기본 Idle 상태로 자연스럽게 복귀

### 모바일 인터랙션

모바일에는 hover가 없으므로 각 축 또는 역량 목록을 탭할 수 있게 해주세요.

- 탭한 축과 라벨 강조
- 해당 역량 설명 표시
- 다른 항목을 탭하면 선택 상태 변경
- 레이더 아래에 5개 역량 목록을 함께 제공
- 작은 화면에서 라벨이 겹치지 않도록 배치
- Idle 모션은 데스크톱보다 이동 범위를 줄여 적용

### 접근성 및 성능

- SVG 기반으로 제작
- 애니메이션은 transform과 opacity 중심으로 구현
- `prefers-reduced-motion: reduce` 환경에서는 반복 모션 제거
- 모션 감소 설정에서는 최종 형태만 fade-in으로 표시
- 키보드 focus로 모든 축을 탐색할 수 있게 구현
- 저사양 모바일 환경에서 프레임 저하가 발생하지 않도록 최적화
- 레이더 그래픽보다 각 역량의 의미와 연결 관계가 먼저 이해되게 구성
