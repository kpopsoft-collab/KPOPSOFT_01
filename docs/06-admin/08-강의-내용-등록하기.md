## 0. 한 줄 요약

어드민에서 정규 클래스를 하나 등록하면 **목록 카드 1장**과 **상세 페이지 1개**가
같이 생긴다. 상세 페이지 주소는 입력한 **슬러그**로 정해진다.

```
어드민  /admin/content/education/regular-classes
   ↓
공개    /education/programs            ← 카드 목록
        /education/programs/<슬러그>   ← 상세 페이지
```

**저장하면 새로고침만으로 바로 반영된다.** 배포를 기다릴 필요가 없다.

## 1. 등록 절차

1. `/admin/content/education/regular-classes` 로 들어간다
2. `새로 만들기`
3. 아래 §2 표대로 입력한다
4. **`공개 노출`을 켠다** — 꺼져 있으면 목록에도 안 나오고 상세 주소는 404다
5. `저장`
6. `/education/programs/<슬러그>` 를 새 탭에서 열어 확인한다

## 2. 입력 항목 — 무엇이 화면 어디에 나오나

### 필수

| 어드민 항목 | 화면 위치 | 비고 |
|---|---|---|
| **과정명** | 상세 히어로 제목 · 카드 제목 | |
| **슬러그** | **주소가 된다** (`/education/programs/ai-tools`) | 영문 소문자·숫자·하이픈만. **나중에 바꾸면 기존 링크가 전부 깨진다** |

### 기본 정보

| 어드민 항목 | 화면 위치 | 비고 |
|---|---|---|
| 부제 | 히어로 제목 아래 한 줄 | 짧게. 긴 설명은 아래 `설명`에 |
| 설명 | 상세 본문 **"이 과정은"** 블록 | 히어로에는 안 나온다 — 같은 문장을 두 번 보여주지 않기 위해서다 |
| 순번 표기 | 카드·히어로의 `01` 같은 표기 | 정렬 순서가 아니라 **표기**일 뿐이다 |
| 기간 | 요약 카드 `기간` | 자유 문자열 (`4주`, `2시간`) |
| 난이도 표기 | 요약 카드 `난이도` | 자유 문자열 (`입문·중급`, `비개발자 환영`) |

### 강의 일정

| 일정 유형 | 입력 | 화면 |
|---|---|---|
| **원데이 클래스** | `강의일` 하나 | `2026년 8월 20일 (하루 과정)` |
| **다회차 클래스** | `시작일`·`종료일` | `2026년 8월 20일 – 9월 17일` |

**날짜는 비워도 된다.** 비우면 요약 카드에 **"상시 모집 · 문의 시 안내"** 로 나온다.
빈칸으로 두지 않는 이유는, 빈칸이 "정보가 없다"가 아니라 "확인하지 못했다"로
읽히기 때문이다.

> 종료일만 입력하는 것은 막혀 있다. 종료일이 시작일보다 빠를 수도 없다.

### 학습 트랙 (여러 개 선택 가능)

`AI 입문` · `실무 활용`

**난이도 표기와 다른 축이다.** 난이도에는 `비개발자 환영` 같은 값도 들어오므로,
목록 페이지의 **트랙 필터**가 쓰는 기준은 이쪽이다. 하나도 안 고르면 필터에서
어떤 트랙을 골라도 이 과정이 안 나온다.

### 이미지

| 항목 | 비고 |
|---|---|
| 과정 이미지 | 16:9로 잘린다. 카드와 상세 상단에 같이 쓰인다 |
| 이미지 대체 텍스트 | **꼭 채운다.** 스크린리더가 읽고, 이미지가 안 뜰 때도 이 문구가 보인다 |
| 이미지 캡션 | 선택. 상세 이미지 아래 작은 글씨 |

이미지를 안 넣으면 카드 색상으로 채운 도형 배경이 대신 들어간다.

### 주차별 커리큘럼

한 줄에 한 항목씩 추가한다.

```
1주 — 주요 AI 도구 지형 파악과 계정·환경 세팅
2주 — 프롬프트 설계: 업무 문서·조사·기획에 적용하기
```

**상세 자료를 올려도 커리큘럼은 계속 보인다.** 수강 여부를 결정하는 근거가
커리큘럼이라, 자료가 있다고 감추지 않는다.

### 카드 색상

목록 카드와 상세 히어로 패널의 배경색. 4과정이 나란히 보이므로 **서로 다른
색**을 고른다.

### SEO (선택)

| 항목 | 비우면 |
|---|---|
| SEO 제목 | `<과정명> \| KPOPSOFT Education` |
| SEO 설명 | 위 `설명` 값 |

### 외부 상세 링크 (선택)

**대부분 비워 둔다.** `http`로 시작하는 주소를 넣으면 **카드가 상세 페이지 대신
그 주소로** 간다. 사내에 따로 만든 상세가 있는 과정을 위한 예외 통로다.
내부 경로(`/…`)를 적으면 무시된다.

## 3. 상세 자료 올리기 (선택)

`자료 방식` 라디오에서 고른다.

| 고르는 값 | 결과 |
|---|---|
| **없음 (커리큘럼 목록만)** | 커리큘럼만 나온다 |
| **상세 자료 (zip 또는 HTML 한 장)** | 커리큘럼 **아래**에 `상세 자료 보기` 버튼이 붙는다 |

자료는 **새 탭에서 원본 그대로** 열린다. 페이지 안에 그리지 않는다.

### zip으로 올려야 하는 경우 — 대부분 이쪽이다

자료에 **이미지·CSS·폰트·서브 페이지가 하나라도 있으면 zip**이다.

```
강의자료.zip
├── index.html      ← 이름이 반드시 index.html
├── assets/
│   ├── photo1.jpg
│   └── style.css
└── prompts.html
```

- 진입 파일 이름은 **`index.html`** 이어야 한다
- 파일 하나당 5MB, 전체 20MB, 300개까지
- 파일명은 **영문·숫자**로. 한글 파일명은 압축 프로그램에 따라 깨져서 이미지가
  안 보일 수 있다 (업로드 시 경고가 뜬다)

### `.html` 한 장으로 올려도 되는 경우

**파일 하나로 완결되는 자료만.** 이미지가 외부 주소(`https://…`)이거나 아예
없고, CSS·JS가 파일 안에 들어 있는 경우다.

> ⚠️ **가장 흔한 실수** — 이미지가 딸린 슬라이드 덱을 `.html` 한 장으로 올리는 것.
> 그러면 `<img src="assets/photo.jpg">`가 가리킬 파일이 서버에 없어서 **사진이
> 전부 안 보인다.** 글자와 레이아웃만 나온다. 이럴 때는 `assets/` 폴더까지 담아
> **zip으로 다시 올린다.**

### 올리기와 저장은 다르다

파일을 고르면 바로 업로드가 시작되지만, **`저장`을 눌러야 화면에 반영된다.**
업로드 중에는 저장 버튼이 잠긴다.

### 자료를 바꾸거나 뺄 때

- **바꾸기**: 새 파일을 올리면 옛 자료는 저장 시 자동으로 정리된다
- **빼기**: `자료 방식`을 `없음`으로 바꾸고 저장

> **이름만 고칠 때는 자료를 건드리지 않는다.** `자료 방식` 라디오를 그대로 두고
> 저장하면 자료는 그대로 남는다. 이 성질이 깨지면 제목 하나 고치다 자료를 통째로
> 날리게 되므로, 폼을 손볼 때마다 이것부터 확인한다.

## 4. 저장 후 확인

| # | 확인 | 어디서 |
|---|---|---|
| 1 | 카드가 목록에 보인다 | `/education/programs` |
| 2 | 트랙 필터로 걸러도 나온다 | 같은 페이지 |
| 3 | 상세 페이지가 열린다 | `/education/programs/<슬러그>` |
| 4 | 기간·난이도·일정·트랙이 요약 카드에 다 있다 | 상세 우측(모바일은 상단) |
| 5 | 커리큘럼이 보인다 | 상세 본문 |
| 6 | **`상세 자료 보기`를 실제로 눌러 본다** | 새 탭에서 자료가 제대로 렌더되는지 |

> 6번을 건너뛰지 않는다. **파일이 올라간 것과 화면이 제대로 나오는 것은 다르다** —
> 실제로 업로드는 성공했는데 새 탭이 깨져 있던 적이 있다
> ([../07-dev/13-작업로그-2026-08-05.md](../07-dev/13-작업로그-2026-08-05.md)).

## 5. 자주 겪는 문제

| 증상 | 원인 | 조치 |
|---|---|---|
| 상세 주소가 404 | `공개 노출`이 꺼져 있다 | 켜고 저장 |
| 목록에 안 나온다 | 같은 이유 | 위와 같음 |
| 트랙 필터에서 안 걸린다 | `학습 트랙`을 하나도 안 골랐다 | 최소 1개 선택 |
| 자료의 사진이 전부 안 보인다 | `.html` 한 장으로 올렸다 | `assets/` 포함 zip으로 재업로드 (§3) |
| 카드는 있는데 눌러도 다른 데로 간다 | `외부 상세 링크`에 주소가 들어 있다 | 비우고 저장 |
| 일정이 "상시 모집"으로 나온다 | 날짜를 안 넣었다 | 의도한 것이면 그대로 둔다 |
| 저장 버튼이 안 눌린다 | 자료 업로드가 진행 중이다 | 끝날 때까지 기다린다 |
