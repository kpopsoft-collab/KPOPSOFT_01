## 1. ver2 → ver3 변경 요약

가장 큰 변경은 **프로그램 분류 체계**입니다. ver2의 평면 6개 프로그램을 3분류 체계로 재편합니다.

| | ver2 | ver3 (IA 기준) |
|---|---|---|
| 프로그램 구조 | 평면 6개 | **3분류** + 정규 클래스 하위 4과정 |
| 섹션 수 | 14개 (Header/Footer 제외) | **8개** |
| VIBEDAYS | 독립 섹션 | **모달** |
| 통계바 | 없음 | **신설** |
| 지난 프로그램 | 없음 (교육 사례로 존재) | **신설** (실제 사례 이미지) |
| 후기 | 일반 인용 카드 | **별점 + 리뷰형** |
| AI Prototype Lab | 대표 프로그램 6개 중 하나 | **완전 폐지** |

### 3분류 체계

```text
01. 조직·기업 맞춤 교육
02. 정규 클래스          (하위 4과정)
03. 지식 공유 커뮤니티 클럽 / 바이브데이즈

```

### 모집 상태 구조 (필수)

모집은 상시가 아니라 **기수제**입니다. 마감·모집 중단·기수 교체가 수시로 일어나므로, 문구를 하드코딩하지 않고 **상태값 하나로 전환**되도록 만듭니다.

```ts
type CohortStatus =
  | "upcoming"  // 모집 예정 — 시작일만 안내, 신청 버튼 비활성
  | "open"      // 모집 중   — 가격·정원·신청 버튼 노출
  | "closed"    // 모집 마감 — "마감되었습니다" + 다음 기수 안내
  | "ended";    // 운영 종료 — 기수 정보 자체를 숨김
```

**1기 현재 상태: 8월 모집 / 9~12월 운영**

```text
모집 기간   2026년 8월
운영 기간   2026년 9월 ~ 12월 (4개월)
가입비      79,000원
```

### 노출 제어 요구사항

- 각 요소(가격 / 정원 / 신청 CTA / 기수 일정 / 다음 기수 안내)를 **개별로 숨길 수 있어야** 합니다. 가격 미정 상태로 모집 예고만 띄우는 경우가 있습니다.
- `closed`일 때 신청 CTA는 **제거가 아니라 비활성 + 사유 표기**입니다. 버튼이 사라지면 마감 사실 자체가 전달되지 않습니다.
- `ended`이면 해당 기수 블록을 통째로 감추고 다음 기수를 노출합니다. 노출할 기수가 없으면 모달은 **소개 콘텐츠(참여 유형 3단계)만** 보여주고 모집 영역을 비웁니다 — 모달 자체가 사라지면 안 됩니다.
- 기수 목록은 배열로 관리하고 `status`로 현재 기수를 판별합니다. `2기 1월-4월` 같은 예정 기수를 미리 넣어둬도 `upcoming`이면 일정만 노출됩니다.
- 상태 전환은 **날짜 자동 계산에 의존하지 않습니다.** 명시적 상태값을 우선합니다 — 모집을 조기 마감하거나 연장하는 운영 판단이 날짜보다 우선하기 때문입니다.

Admin 연동 전까지는 `education-content.ts`의 상수로 두되, 위 필드 구조를 그대로 유지해 나중에 DB로 옮길 때 UI를 고치지 않아도 되게 합니다.

```text

```

- 별점은 시각적 별 아이콘과 함께 텍스트로도 제공합니다(`5점 만점에 5점`) — 스크린리더 대응.
- 리뷰를 과하게 다듬지 않습니다. 구어체를 허용합니다.
- 평균 별점을 섹션 상단에 요약 표시합니다.

```text
Q. 코딩을 전혀 몰라도 수강할 수 있나요?
A. 네, 가능합니다. Vibe Coding이나 AI 활용 과정은 비개발자도 충분히 따라올
   수 있도록 설계되어 있습니다. 코드보다 개념과 실습에 집중합니다.

A. 네. 수료 후 카카오톡 오픈채팅 커뮤니티에서 질의응답 지원과 피드백을 제공합니다.
```

```text
Q. 정규 클래스는 온라인인가요, 오프라인인가요?
A. 정규 클래스는 오프라인으로 진행합니다. 조직·기업 맞춤 교육은 방문 교육까지
```

## 3. 교육 프로그램 상세 페이지 (2차 범위 — 이번엔 구현하지 않음)

IA에서 회색 처리된 영역입니다. **이번 개편에서는 만들지 않습니다.**

```text
교육 프로그램 (상세)
├─ 프로그램 정보
│   ├─ 조직·기업 맞춤 교육
│   ├─ 정규 클래스
│   └─ 지식 공유 커뮤니티 클럽 / 바이브데이즈
├─ 지난 프로그램
├─ 강의 자료실
├─ 인사이트 / 매거진
├─ (미정) 나의 바이브데이저 테스트
└─ Footer
```

### 이번 범위에서 해야 할 것

**진입 경로만 미리 만듭니다.** SECTION 05의 각 과정 카드에서 상세 페이지로 가는 링크를 배치하되, 페이지가 없는 동안 링크가 404로 떨어지지 않게 처리합니다.

처리 방식은 구현 시 아래 중 하나를 택합니다.

1. 링크를 비활성 상태로 두고 `준비 중` 표기 — 가장 안전
2. `/education/programs/[slug]`를 만들되 "준비 중" 안내만 렌더

기획 의도는 "경로가 있어야 함"이므로, 최소한 **어디로 이어질지가 UI에서 드러나야** 합니다.

## 6. 구현 완료 조건

- Education 페이지가 8개 섹션(Header/Footer 제외)으로 구성된다.
- 프로그램이 3분류 + 정규 클래스 4과정 구조로 노출된다.
- 통계바와 지난 프로그램 섹션이 신설되어 있다.
- VIBEDAYS가 모달로 열리고, 키보드·포커스·스크롤 잠금이 정상 동작한다.
- 홈 Contact의 클럽 링크에서도 모달이 열린다.
- 후기에 별점이 표시되고 스크린리더로 값이 읽힌다.
- FAQ가 단일 아코디언 목록이다.
- CONTACT가 이메일 단일 입력으로 시작한다.
- 정규 클래스 각 과정에서 상세 페이지로의 진입 경로가 UI에 드러난다(404 없음).
- `AI Prototype Lab` 문자열이 페이지·문의 옵션·SEO 어디에도 남아 있지 않다.
- 제거 대상 6개 섹션 컴포넌트 파일이 삭제되지 않고 남아 있다.
- Desktop·Tablet·Mobile에서 정상 동작한다.
