## Admin 변경

| 대상 | 변경 |
|---|---|
| 프로그램 관리 | 평면 목록 → 분류(3종) + 정규 클래스 하위 과정 2단 구조 |
| 교육 결과물 관리 | 비활성 (스키마는 유지) |
| 교육 사례 관리 | **지난 프로그램**으로 명칭·용도 변경 |
| VIBEDAYS 관리 | 섹션 → 모달 콘텐츠 관리. 기수 정보(회차·기간·가격) 필드 추가 |
| 통계바 | 신규 — 4개 지표 라벨·수치 관리 |
| 후기 관리 | 별점 필드 추가 |
| FAQ 관리 | 개인/기업 구분 필드 제거, 단일 목록 |

## 확정된 결정 사항

| 항목 | 결정 |
|---|---|
| AI Prototype Lab | 완전 폐지 |
| 제거 섹션 6개 | 파일 보존, import만 차단 |
| 홈 Contact 교육 문의 유형 | 유지. 별도 강조 뱃지 없음 |
| AI 활용 입문 + AI 업무 활용 | 정규 클래스 `AI 활용` 단일 과정으로 통합 |
| 웹·앱 제작 | 신규 과정 (ver2에 없던 8주 과정) |
| 홈 섹션 순서 | 핵심 비즈니스가 포트폴리오보다 **위**로 이동 (현재 코드와 반대) |
