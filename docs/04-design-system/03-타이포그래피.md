## 3. TYPOGRAPHY

Use a bold modern grotesk sans-serif.

Suggested font direction:

English:
- Inter
- Geist
- Manrope
- Arial Neue
- General Sans style

Korean:
- Pretendard
- SUIT
- Wanted Sans

Typography should be large and graphic.

### Display Heading

Desktop:
64–100px

Mobile:
42–58px

Weight:
700–800

Line-height:
1.0–1.1
(현재 토큰 `text-display` = 1.1. 한글은 라틴보다 세로 밀도가 높아 0.95처럼 지나치게 좁으면 여러 줄에서 답답하게 보이므로 1.0 이상 유지. 순수 장식용 대형 숫자는 `leading-none`로 개별 예외.)

Letter spacing:
-0.04em

#### 긴 헤드라인 — `text-display-long` (38–76px)

`text-display`의 상한 100px은 "아이디어를 / 작동하는 기술로."처럼 **짧은 두 줄**을
전제로 잡은 크기다. 기획서가 확정한 문장이 그보다 길면 지정된 줄바꿈을 지키지
못하고 세 줄, 네 줄로 접힌다 — 이때 크기를 줄이는 대신 줄을 늘리면 첫 화면에서
CTA가 밀려나고, 확정 카피의 호흡도 깨진다.

그래서 위계는 display 자리에 두되 상한만 낮춘 단계를 둔다. Section Heading(72px)
보다는 크게 남아 h1과 h2가 같은 크기로 보이지 않는다.

- 적용 예: `/education` 히어로 "AI를 배우고, 만들고, / 실제 업무에 적용합니다."
- 판단 기준: 확정된 줄바꿈대로 두 줄에 들어가지 않으면 이 단계를 쓴다.

### Section Heading

Desktop:
48–72px

Mobile:
34–48px

Weight:
700

Line-height:
1.12–1.18
(현재 토큰 `text-section` = 1.15. 2–3줄로 감기는 한글 제목의 줄 사이가 붙어 보이지 않도록 확보한 값.)


### Body

Desktop:
17–20px

Mobile:
16–18px

Line-height:
1.5–1.7


### 한글 줄바꿈 (Korean line-breaking)

모든 텍스트는 어절(단어) 단위로 줄바꿈한다. 어절 중간에서 글자가 잘려 다음 줄로 넘어가는 것(예: "실제 / 로", "구축합니 / 다")을 금지한다.

- 전역 규칙: `body`에 `word-break: keep-all` 적용 → 헤딩·본문·캡션·타임라인 등 모든 텍스트에 상속된다. 컴포넌트마다 개별로 다시 지정하지 않는다.
- 예외: 긴 영문 단어·URL·코드처럼 keep-all로 인해 컨테이너를 넘칠 수 있는 경우에만 해당 요소에 `break-words`(overflow-wrap: anywhere)를 국소 적용한다.
- `<br>`로 강제 줄바꿈한 헤딩도 각 줄이 어절 경계에서 끊기는지 확인한다.


### Eyebrow Label

12–14px

Uppercase or compact labeling style.

Use typography as part of the visual composition.

Headlines may:

- break across unusual lines
- align with geometric shapes
- partially overlap graphics
- occupy 40–70% of viewport width

Do not center every headline.

Prefer asymmetrical editorial placement.
