### Program Cards

Program cards should not look like SaaS dashboard cards.

Each program card includes:

- small index number
- program name
- short description
- expertise tags
- simple geometric graphic
- arrow action

Programs:

01
AI 업무 활용

02
Vibe Coding

03
Software Development

04
Web & App Development

05
AI Automation

06
AI Prototype Lab

07
기업 맞춤형 교육


Cards can use:

- asymmetric sizing
- different background colors
- modular grid arrangements
- occasional large feature card

### Testimonial Component

Create horizontal testimonial strips.

Each testimonial should include:

- short quote
- company or participant type
- program category
- result or outcome

Use minimal avatars.

Prioritize typography.

Testimonials may appear inside:

- colored horizontal bands
- rating-style rows
- alternating quote blocks

Avoid conventional white testimonial cards with large shadows.


--------------------------------------------------

### Process Diagram

Visualize the KPOPSOFT process:

01
Understand

문제와 목표 정의


02
Design

서비스 및 교육 구조 설계


03
Build

소프트웨어, 자동화, 프로토타입 개발


04
Learn

실습 중심 교육 및 기술 이전


05
Scale

조직과 서비스에 확장


Use:

- lines
- nodes
- circles
- arrows
- overlapping geometric shapes

Create a diagram-like visual composition rather than a standard row of five icons.
