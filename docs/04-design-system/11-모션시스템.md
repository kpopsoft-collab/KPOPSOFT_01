## 10. MOTION SYSTEM

Motion should be playful but restrained.

Use:

- shape rotation
- slow floating movement
- horizontal marquee
- scroll-triggered shape assembly
- underline drawing
- number counting
- card reveal
- text masking transition


Animation duration:

Fast interaction:
150–250ms

UI transition:
300–500ms

Editorial section animation:
600–900ms


Avoid:

- excessive parallax
- constant bouncing
- mouse-following cursors
- aggressive scroll hijacking
