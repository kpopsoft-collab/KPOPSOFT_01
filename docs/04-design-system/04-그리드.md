## 4. GRID SYSTEM

Desktop:

Maximum content width:
1440px

Main content width:
1280px

12-column grid

Outer margin:
32–64px

Section vertical spacing:
120–200px


Tablet:

8-column grid


Mobile:

4-column grid

Horizontal padding:
20–24px

Section spacing:
72–110px


Layout principle:

Use a controlled mixture of:

- full-width sections
- asymmetric 2-column layouts
- 3-column card grids
- horizontal timelines
- large editorial typography blocks
- modular information cards


Avoid making every section the same rectangular card grid.
