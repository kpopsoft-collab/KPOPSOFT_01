## 5. SHAPE SYSTEM

Create reusable graphical shapes for the entire brand experience.

Core shape vocabulary:

### Circle
Represents:
connection, people, knowledge

### Arch
Represents:
growth, progress, entry point

### Star
Represents:
AI insight, discovery, innovation

### Wave
Represents:
iteration, process, continuous learning

교육(`/education`) 페이지의 Wave는 항상 Mint `#63C7B2` 계열(`text-brand-mint`)로 쓴다. 다른 액센트 컬러를 적용하지 않는다.

### Capsule
Represents:
technology tags, skills, modules


Shapes may be:

- cropped by containers
- layered
- partially outside grid boundaries
- combined to form abstract illustrations

The same visual vocabulary must appear consistently throughout:

- Hero
- Program cards
- Process diagrams
- Testimonials
- CTA banners
- Footer
