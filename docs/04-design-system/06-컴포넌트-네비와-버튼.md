## 6. COMPONENT SYSTEM


### Navigation

Minimal horizontal navigation.

Desktop:

Left:
KPOPSOFT wordmark

Center or right:

- About
- Programs
- Software
- AI Lab
- Experts
- Contact

Primary CTA:

프로젝트 문의
or
교육 문의


Navigation style:

Height:
64–76px

Background:
transparent or ivory

Small rounded CTA button.

Avoid large pill navigation containers.


--------------------------------------------------

### Buttons

Primary button:

Height:
48–54px

Padding:
20–28px

Border radius:
999px

Background:
Primary Blue

Text:
White


Secondary button:

Transparent background

1–1.5px dark border

Optional arrow icon


Buttons should feel compact and confident.

Hover behavior:

- slight horizontal arrow movement
- subtle background change
- no excessive bounce animation
