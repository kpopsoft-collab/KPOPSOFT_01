# KPOPSOFT 홈 랜딩페이지 변경 기획안

## 1. 개편 목적

현재 홈은 Software, AI Solutions, Education, 강사진, Work, Insights 등 모든 내용을 한 페이지에서 설명하고 있어 길고 핵심이 분산되어 보입니다.

개편 홈은 다음 한 가지 목적에 집중합니다.

> **KPOPSOFT가 소프트웨어와 AI 솔루션을 실제로 구현하는 제작사임을 사례 중심으로 보여주고, 프로젝트 의뢰로 연결한다.**

Education의 상세 콘텐츠는 `/education` 페이지로 분리하고, 홈에서는 짧은 배너 형태로만 연결합니다.

---

## 2. 방문자가 10초 안에 이해해야 하는 내용

- KPOPSOFT는 웹·앱·관리자 시스템·내부 업무 도구를 제작한다.
- AI를 단순히 제안하는 것이 아니라 실제 업무에 적용 가능한 솔루션으로 구현한다.
- 실제 제작 사례와 결과 화면이 있다.
- 기획서가 없어도 프로젝트를 의뢰할 수 있다.
- 교육 사업은 별도 Education 페이지에서 확인할 수 있다.

## 4. 브랜드 심볼 사용 원칙

KPOPSOFT의 세 가지 심볼은 각각 핵심 비즈니스를 의미합니다.

- 파란 동그라미: Software
- 빨간 스파크: AI Solutions
- 초록 물결: Education

세 요소가 함께 KPOPSOFT를 구성하지만, 홈에서 심볼 의미를 길게 설명하지 않습니다.

다음 영역에서 자연스럽게 활용합니다.

- 섹션 구분
- 카테고리 컬러
- 카드 포인트
- 마이크로 모션
- Education 배너
- 브랜드 패턴

홈의 중심은 심볼 설명이 아니라 **제작 사례와 프로젝트 의뢰**입니다.

```text
제조기업 · Digital Product

기업 교육 운영 플랫폼
교육기관 · Web Platform
```

### 카드 이미지 원칙

이미지는 카드 면적의 약 65~75%를 차지합니다.

- 웹서비스: 실제 전체 화면
- 앱: 디바이스 목업
- 관리자: 브라우저 대시보드
- AI 자동화: 입력 → 처리 → 결과
- Prototype: 주요 화면 콜라주

별도의 `사례 보기` 버튼은 반복하지 않습니다.

카드 전체를 클릭할 수 있게 하고 Hover 시 다음 정도만 적용합니다.

- 이미지 1.02~1.04 확대
- 화살표 또는 제목 미세 이동
- 과도한 그림자와 3D 효과 금지

프로젝트가 6개 이상 쌓이면 섹션 하단에만 다음 링크를 표시합니다.

```text
전체 프로젝트 보기 →
```

## 9. 디자인 방향

### 비주얼 비율

```text
실제 프로젝트 이미지 60%
텍스트와 브랜드 그래픽 40%
```

### 전체 무드

- 실제 화면 중심
- 넓은 여백
- 에디토리얼한 사례 배치
- 전문적이지만 지나치게 딱딱하지 않은 인상
- KPOPSOFT의 원·스파크·물결 그래픽 활용
- 기술을 과장하지 않는 태도
- 실제 구현 역량이 느껴지는 제작사 이미지

### 피해야 할 표현

- 모든 카드를 같은 형태로 반복
- 카드마다 CTA 버튼 반복
- 추상적인 AI 뇌·로봇 이미지
- 과도한 네온과 미래형 그래픽
- 의미 없는 3D 오브젝트
- 긴 텍스트 중심 섹션
- 홈에 교육 상세 콘텐츠 재노출

- 기존 Admin 데이터를 재사용한다.

3. 기존 Header 및 Footer
4. 기존 Work 데이터 구조
5. 기존 Admin 구조
