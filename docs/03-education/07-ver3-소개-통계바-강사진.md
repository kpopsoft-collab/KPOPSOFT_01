## SECTION 02. KPOPSOFT 교육프로그램 소개

Hero 역할과 3분류 소개를 겸합니다.

#### Eyebrow

```text
KPOPSOFT EDUCATION
```

#### Title

```text
배우며, 만들고
적용까지.
```

#### Description

```text
누구나 쉽게 AI를 알고
시작할 수 있게 교육합니다
```

> ver2 Description에 있던 `AI Prototype` 언급은 제거합니다.
> 줄바꿈은 의미 단위로 고정합니다.

#### 3분류 소개

세 카드를 동일 비중으로 배치하고, 각각 05 프로그램 정보의 해당 앵커로 이동합니다.

```text
조직·기업 맞춤 교육
회사 상황과 직무에 맞춰 커리큘럼 설계 및 제공
→ #program-org

정규 클래스
실무에 바로 쓰는 4가지 과정
→ #program-regular

지식 공유 커뮤니티 클럽 / 바이브데이즈
혼자가 아니라 함께, 매월 실험하고 피드백받는 커뮤니티
→ #program-club
```

> 카드 설명처럼 **한 문장으로 끝나는 짧은 문구는 마침표를 찍지 않습니다.**
> 여러 문장이 이어지는 본문과 헤드라인(`적용까지.`)은 종전대로 마침표를 씁니다.

#### CTA

```text
[무료 상담 신청하기]
```

## SECTION 03. 통계바

신설 섹션. 홈 통계바와 동일한 컴포넌트를 재사용하되 항목이 다릅니다.

```text
교육 수료생
정규 클래스
평균 만족도
클럽 참가자
```

- 구체 수치는 Admin에서 관리합니다. 확정 전까지는 홈 통계바(`1,800+`, `96%`)와 모순되지 않는 값을 씁니다.
- 배경색으로 위아래 섹션과 분리합니다.
- Desktop 4열 / Mobile 2×2.

---

## SECTION 04. 전문 강사진 소개

ver2 §16을 유지합니다. 카드 필드·레이아웃 변경 없음.

#### 이미지 원칙

**실제 강사 이미지를 사용합니다** (IA 주석). 일러스트·이니셜 아바타로 대체하지 않습니다. 실제 사진이 없는 강사는 카드를 노출하지 않거나 브랜드 Placeholder를 씁니다.

#### 데이터

홈과 동일한 `getPublicExperts()`를 그대로 재사용합니다 (ver2 §28 유지). 페이지마다 중복 등록하지 않습니다.

#### 담당 영역 표기

ver2의 `Prototype & Vibe Coding` 표기에서 `Prototype`을 제거하고 `Vibe Coding`으로 정리합니다.
