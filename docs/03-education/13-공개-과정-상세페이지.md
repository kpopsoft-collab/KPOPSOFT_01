## 1. 라우트

| 경로 | 파일 | 무엇 |
|------|------|------|
| `/education/programs` | `src/app/education/programs/page.tsx` | 정규 클래스 4과정 목록 + 트랙 필터 |
| `/education/programs/[slug]` | `.../[slug]/page.tsx` | 과정 상세 |

둘 다 `force-dynamic`이다. 어드민이 고치면 **새로고침만으로 보여야** 하므로
`generateStaticParams`를 쓰지 않는다. 목록은 예전에 빈 페이지라 걸어 뒀던
`robots: { index: false }`를 **지웠다** — 두면 어드민이 공개한 과정이 검색에
영원히 안 나온다.

들어오는 길은 `/education` 프로그램 카드의 `정규 교육과정 알아보기` CTA다.
`/education`의 `edu-programs`는 정규 클래스를 3분류 중 하나로 **소개**만 하고,
이 페이지가 4과정을 나란히 놓고 **비교·선택**하게 한다. 두 화면이 같은 일을
하면 하나가 곧 방치된다.

## 3. 데이터 경로

```text
목록  getPublicRegularClasses()      → REGULAR_CLASS_PUBLIC_COLUMNS
상세  getPublicRegularClassBySlug()  → 위 상수 + detail_html, detail_bundle_path
```

`src/lib/public-content.ts`. 상세 전용 컬럼을 **공통 상수에 넣지 않는다** —
목록이 쓰지도 않는 컬럼 때문에 `/education`까지 같이 폴백으로 떨어질 이유가 없다.

번들의 공개 URL은 DB에 없다. `detail_bundle_path`(폴더)만 저장하고 **서버에서**
`…/index.html` URL을 조립한다. 클라이언트에서 만들면 프로젝트 ref가 화면 코드에
흩어진다.

### 없는 행과 실패한 조회를 **구분한다**

| 상황 | 결과 |
|------|------|
| 조회 성공 + 행 없음 (삭제·비공개) | **404** |
| 조회 자체가 실패 (장애) | **정적 폴백**(`education-content.ts`) |

구분하지 않으면, 목록은 폴백으로 4개 카드를 그리는데 상세만 404가 나서
**목록 카드가 전부 깨진 링크**가 된다. 비공개 필터링은 RLS가 이미 하므로
페이지에서 `is_published`를 다시 검사하지 않는다.

목록 리더도 `read()` 공용 경로를 쓰지 않고 별도다 — 공용 경로는 `0행 = 폴백`이라,
**모든 과정을 일부러 비공개로 돌린 정상 상태**에서 정적 4행이 되살아난다.

## 4. 상세 본문 — **분기는 없다**

```text
커리큘럼        항상 그린다 (curriculum 배열)
상세 자료 링크   detail_bundle_path 가 있을 때 본문 끝에 덧붙는다
```

> **2026-08-05에 바뀌었다.** 예전에는 본문이 셋 중 하나였다 —
> 업로드 HTML을 **인라인으로 그리거나**, 번들 링크를 놓거나, 커리큘럼을 그리거나.
> 그 구조를 폐지했다. 이유 둘:
>
> 1. 정제기가 `<script>`·`@keyframes`·`position`을 지우므로 **완성된 문서 한 장을
>    인라인으로 그리면 빈 화면이 된다.** 실측 29,435px 중 대부분이 빈 기둥이었고
>    슬라이드 25장 중 24장이 `visibility:hidden`이었다.
> 2. 업로드가 있으면 **커리큘럼이 통째로 사라졌다.** 커리큘럼은 수강 결정의
>    근거라 조건부로 둘 수 없다.
>
> 전말 — [결정기록 06 01-현황분석](../08-decisions/06-course-detail-page-redesign/01-현황분석-무엇이-깨졌나.md).

### 자료는 새 탭이고, 주소는 **우리 라우트**다

```text
/course-assets/<uuid>/index.html   ← src/app/course-assets/[...path]/route.ts
        └ Storage education/<uuid>/… 를 가져와 Content-Type만 다시 붙인다
```

**Supabase Storage 공개 URL을 직접 쓰면 안 된다.** Storage가 HTML을 의도적으로
`text/plain`으로 내려서, 새 탭에 열면 페이지가 아니라 **소스 코드**가 보인다.
버킷 설정으로 못 바꾼다. 2026-08-04에 올린 zip 번들도 이 때문에 깨져 있었다.

우리 도메인으로 내보내면서도 origin을 격리하는 장치가
**`Content-Security-Policy: sandbox`** 다 — `allow-same-origin`을 주지 않아
문서가 불투명 origin(`null`)이 되고, `localStorage`·`document.cookie`에 닿지
못한다. 실측으로 확인했다. **이 헤더를 빼면 업로드된 JS가 우리 세션을 읽는다.**

라우트가 잠근 것 5가지(`<uuid>/` 모양 · DB 등록 경로만 · 확장자 허용목록 ·
`nosniff` · `noindex`)는 그 파일 머리 주석과
[결정기록 06 03](../08-decisions/06-course-detail-page-redesign/03-화면구조-결정.md) D3-정정에 있다.

### release gate — G1~G5는 **이 구조에서 무의미해졌다**

인라인 렌더링 자체가 사라졌으므로 G2~G4(정제·`dangerouslySetInnerHTML`·셸)는
지킬 코드가 없다. G1(목록은 `detail_html` 제외)·G5(일정 표기 함수 하나)는 유효하다.

**G6(CSP)은 2026-08-05에 Report-Only로 적용되면서 닫혔다** — 기준 문서가
[../07-dev/14-CSP-정책과-적용.md](../07-dev/14-CSP-정책과-적용.md)로 옮겨졌다.
그 문서 §4가 **`/course-assets`를 전역 CSP에서 제외하는 이유**를 담고 있다 —
제외가 풀리면 위 자료 링크가 통째로 깨진다.

## 5. 일부러 만들지 않은 것

**상세 페이지의 강사진·후기·FAQ 블록.** 요구사항이 "(선택)"으로 뒀고, 특히 후기는
`EduReview.program`이 자유 문자열이라 이 과정 것이라고 판단할 기준이 없다.
잘못 매칭해 **다른 과정 후기를 붙이느니** 블록을 빼는 편이 낫다.
붙이려면 후기에 과정 FK나 slug를 먼저 만들어야 한다.

**신청 폼**도 범위 밖이다. 하단 CTA는 기존 문의 섹션으로 보낸다.

```text
① Breadcrumb        교육 › 정규 클래스 › <과정명>
② Hero              accent 패널 — 순번 / 과정명 / 부제 / 일정 한 줄
                    ※ 긴 설명은 여기 없다. ⑤와 중복되기 때문이다
──── lg 이상 비대칭 2단 ────────────────────────────
│ 본문 8칸                    │ ③ 요약 카드 4칸 sticky │
│ ④ 대표 이미지                │    기간·난이도·일정      │
│ ⑤ 이 과정은 (설명)            │    트랙 태그            │
│ ⑥ 무엇을 배우나요 — 커리큘럼     │    [교육 문의하기]       │
│ ⑦ 상세 자료 (있을 때)          │    [상세 자료 보기 ↗]    │
────────────────────────────────────────────────
⑧ 다른 과정 3장     ⑨ 문의 CTA     ⑩ 모바일 하단 고정 바(lg 미만)
```

바꾼 이유는 [결정기록 06 02-조사](../08-decisions/06-course-detail-page-redesign/02-조사-상세페이지-구조.md)다.
요점 셋 — **커리큘럼이 결정을 만든다**(그래서 항상 그린다), **핵심 사실과
CTA는 스크롤 내내 붙어 있어야 한다**(요약 카드), **막다른 길을 만들지
않는다**(breadcrumb·다른 과정).

일정이 없으면 항목을 감추지 않고 **"상시 모집 · 문의 시 안내"** 로 적는다.
빈칸은 "정보가 없다"가 아니라 "확인하지 못했다"로 읽힌다.
