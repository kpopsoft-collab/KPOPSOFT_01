## 13. 교육 문의

### 제목

> 어떤 교육이 필요한지부터  
> 함께 설계합니다.

### 보조 문구

> 대상과 목적, 현재 AI 활용 수준을 알려주시면 적합한 프로그램과 진행 방식을 제안해드립니다.

### 문의 유형

- 개인 교육
- 기업·조직 교육

선택 유형에 따라 폼 항목이 달라지게 해주세요.

### 공통 필수 항목

- 문의 유형
- 이름 또는 회사명
- 이메일
- 연락처
- 관심 교육
- 문의 내용

### 기업교육 추가 항목

- 예상 참여 인원
- 희망 일정
- 교육 대상 및 직무
- 교육 목적
- 현재 AI 활용 수준

CTA:

> 교육 상담 요청하기

완료 메시지:

> 문의가 정상적으로 접수되었습니다. 확인 후 빠르게 연락드리겠습니다.

### 레이아웃 및 인터랙션

- 페이지를 마무리하는 큰 라운드형 CTA 컨테이너
- 왼쪽 대형 카피, 오른쪽 또는 하단 문의 폼
- Green Wave와 Blue Circle 배경 그래픽
- 문의 유형 전환 시 폼 높이가 자연스럽게 변경
- 필수값과 이메일 형식 검증
- 오류 문구는 해당 필드 가까이에 표시
- 제출 중 중복 클릭 방지

## 15. 모션 원칙

- 섹션 진입: 0.6~0.9초
- Hover: 0.2~0.3초
- 프로그램 전환: 0.5~0.7초
- 패럴랙스: 최대 8~16px
- 이미지 확대: 최대 1.03~1.05
- 반복 장식 모션: 5~8초
- 한 화면에서 주목을 끄는 반복 모션은 2개 이하
- 갑자기 튀는 Easing 금지
- 독서를 방해하는 반복 모션 금지
- 모바일 모션 범위는 데스크톱의 50% 이하
- 화면 밖 반복 애니메이션 일시 중지
- prefers-reduced-motion 대응

---

## 16. 반응형

점검 기준:

- 1440px
- 1024px
- 768px
- 390px

모바일 변경:

- Sticky 프로그램을 일반 세로 카드로 변경
- 자동 마키를 Swipe 캐러셀로 변경
- 장식 그래픽과 패럴랙스 축소
- 프로그램, 강사, 후기 카드가 잘리지 않게 구성
- 모달은 전체 화면 또는 바텀시트
- 터치 영역 최소 44px 확보

---

## 17. 접근성 및 성능

- 의미 있는 이미지에 대체 텍스트 제공
- 장식 그래픽은 스크린리더에서 제외
- 키보드로 링크, 카드, 모달과 아코디언 사용 가능
- 명확한 Focus-visible 상태
- 텍스트 명도 대비 확보
- SVG, Transform, Opacity 중심의 모션 구현
- 교육 사진을 WebP 또는 AVIF로 최적화
- 화면 밖 이미지 Lazy Loading
- 이미지 비율을 사전 지정해 Layout Shift 방지
- 캐러셀과 반복 모션에 일시 정지 기능 제공

## 18. 작업 시 주의사항

- KPOPSOFT 디자인을 Bevel 스타일로 교체하지 마세요.
- Bevel의 색상, 그래픽, 앱 화면과 무지개 Blur를 복제하지 마세요.
- Bevel은 레이아웃과 인터랙션 원리만 참고해주세요.
- 기존 파란 원, 빨간 스파크와 초록 물결을 우선 사용해주세요.
- 확정 문구의 의미를 임의로 변경하지 마세요.
- 확인되지 않은 수치, 후기와 성과를 만들지 마세요.
- 교육 방식 독립 섹션을 다시 추가하지 마세요.
- 기업교육과 바이브데이즈 독립 섹션을 메인에 중복 추가하지 마세요.
- 기업교육은 상세 페이지, 바이브데이즈는 상세 모달로 연결해주세요.
- 기존 코드 구조를 확인하고 재사용 가능한 컴포넌트 중심으로 수정해주세요.
- 데스크톱과 모바일을 모두 점검해주세요.
- 완료 후 변경 파일 목록과 주요 수정 내용을 요약해주세요.
