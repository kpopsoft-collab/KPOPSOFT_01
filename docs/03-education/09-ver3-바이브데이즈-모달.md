## 모달 — 바이브데이즈 랜딩

#### 헤드

```text
성장하는 원동력을 찾고 있다면?
이런 분이라면 바이브데이즈 클럽이 딱이에요!
여러 바이브데이저들의 성장의 날들이 모여
바이브데이즈를 만듭니다
```

#### 참여 유형 3단계

```text
마스터 바이브데이저 : 지식과 솔루션을 나누는 사람
  · 지식기여자로 성장하고 오디언스를 획득하고 싶은 분
  · 개인 브랜딩이 필요한 분

액티브 바이브데이저 : 경험을 나누는 사람
  · 다양한 바이브데이저와 교류하며 성장하고 싶은 분

바이브데이저 : 함께 배우는 사람
  · 내 업무에 AI를 반영하고 효율화하고 싶은 분
  · 다른 동료들과 함께 AI를 학습하고 싶은 분
  · 함께 성장하고 싶은 분
```

> ver2 §11의 캐릭터 역할(NEW VIBER / VIBE MAKER / VIBE SHARER)은 위 3단계 명칭으로 대체합니다.

#### 모집 상태 구조 (필수)

모집은 상시가 아니라 **기수제**입니다. 마감·모집 중단·기수 교체가 수시로 일어나므로, 문구를 하드코딩하지 않고 **상태값 하나로 전환**되도록 만듭니다.

```ts
type CohortStatus =
  | "upcoming"  // 모집 예정 — 시작일만 안내, 신청 버튼 비활성
  | "open"      // 모집 중   — 가격·정원·신청 버튼 노출
  | "closed"    // 모집 마감 — "마감되었습니다" + 다음 기수 안내
  | "ended";    // 운영 종료 — 기수 정보 자체를 숨김
```

**1기 현재 상태: 8월 모집 / 9~12월 운영**

```text
모집 기간   2026년 8월
운영 기간   2026년 9월 ~ 12월 (4개월)
가입비      79,000원
```

#### 노출 제어 요구사항

- 각 요소(가격 / 정원 / 신청 CTA / 기수 일정 / 다음 기수 안내)를 **개별로 숨길 수 있어야** 합니다. 가격 미정 상태로 모집 예고만 띄우는 경우가 있습니다.
- `closed`일 때 신청 CTA는 **제거가 아니라 비활성 + 사유 표기**입니다. 버튼이 사라지면 마감 사실 자체가 전달되지 않습니다.
- `ended`이면 해당 기수 블록을 통째로 감추고 다음 기수를 노출합니다. 노출할 기수가 없으면 모달은 **소개 콘텐츠(참여 유형 3단계)만** 보여주고 모집 영역을 비웁니다 — 모달 자체가 사라지면 안 됩니다.
- 기수 목록은 배열로 관리하고 `status`로 현재 기수를 판별합니다. `2기 1월-4월` 같은 예정 기수를 미리 넣어둬도 `upcoming`이면 일정만 노출됩니다.
- 상태 전환은 **날짜 자동 계산에 의존하지 않습니다.** 명시적 상태값을 우선합니다 — 모집을 조기 마감하거나 연장하는 운영 판단이 날짜보다 우선하기 때문입니다.

Admin 연동 전까지는 `education-content.ts`의 상수로 두되, 위 필드 구조를 그대로 유지해 나중에 DB로 옮길 때 UI를 고치지 않아도 되게 합니다.

#### 운영 정보

```text
1기 가입하기 79,000원
1기 운영기간 9월-12월(4개월간) 월 1회 오프라인 모임

· 월별 공통 미션 주제 중 선택 후 과업 진행하기
· 과업별 진행 방법 및 힌트집 제공
· 자유롭게 진행 후 진행 과정 공유 및 막히는 지점 질의응답 시간을
  바이브데이즈 정기 모임에서 해결함
· 미참석자에게도 세미나 회의록 요약본 내용 제공
```

#### 클로징

```text
혼자서는 어려웠던 AI 학습,
실험부터 피드백까지의 선순환을 매월 경험하세요.
```

#### 기수 안내

```text
2기 1월-4월 / 3기 5월-8월 / 4기 9월-12월
```

#### 모달 요구사항

- Esc 키와 배경 클릭으로 닫힙니다.
- 열릴 때 포커스를 모달 안으로 가두고, 닫히면 트리거 버튼으로 포커스를 되돌립니다.
- 배경 스크롤을 잠급니다.
- 내용이 길어 모달 내부는 세로 스크롤됩니다. Mobile에서는 전체 화면(full-screen sheet)으로 전환합니다.
- 홈 Contact의 `지식 공유 커뮤니티 클럽 / 바이브데이즈` 링크에서도 이 모달이 열립니다 (`/education#program-club`).
