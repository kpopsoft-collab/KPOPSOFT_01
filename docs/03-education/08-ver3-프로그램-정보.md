## SECTION 05. 교육 프로그램 정보

페이지의 핵심 섹션입니다. 3분류를 순서대로 배치합니다.

### 5.1 조직·기업 맞춤 교육 `#program-org`

ver2 §13(기업 맞춤형 교육)의 내용을 이 블록으로 흡수합니다.

```text
회사 상황과 직무에 맞춰 설계합니다.

인원, 직무, 기간에 따라 커리큘럼을 맞춤형으로 구성합니다.
팀 단위(5명 이상)부터 진행 가능합니다.
```

맞춤 설계 항목·교육 형태는 ver2 §13을 유지합니다.

CTA:

```text
[기업 교육 문의하기]
```

### 5.2 정규 클래스 `#program-regular`

#### 섹션 헤더

```text
정규 클래스 교육 과정

실무에 바로 쓰는 4가지 과정
이론이 아닌 결과물 중심. 수료하면 포트폴리오가 생깁니다.
```

#### 4과정

**01. AI 활용 — AI 도구 마스터**

```text
ChatGPT, Claude, Cursor 등 현업에서 즉시 쓸 수 있는
AI 툴을 실무 프로젝트와 함께 배웁니다.

기간 4주 · 입문·중급
```

**02. Vibe Coding — AI와 함께 코딩하기**

```text
코드를 몰라도 괜찮습니다.
AI를 페어 프로그래머로 삼아
아이디어를 실제 소프트웨어로 만드세요.

기간 6주 · 비개발자 환영
```

**03. 웹·앱 제작 — 나만의 서비스 만들기**

```text
기획부터 배포까지.
웹사이트와 모바일 앱을 직접 설계하고 완성하는 실전 코스입니다.

기간 8주 · 중급
```

**04. 업무 자동화 — 반복 업무 자동화**

```text
보고서 자동화, 데이터 수집, 알림 시스템을 직접 구축합니다.

기간 3주 · 입문·중급
```

#### 카드 필수 정보

```text
과정명 / 한 줄 부제 / 설명 / 기간 / 난이도 / 대표 이미지 / 상세 페이지 링크
```

#### 상세 페이지 진입 경로

IA 주석: *"교육프로그램 페이지는 아직 구현 안 할건데, 교육프로그램정보 영역에서 페이지 이동 경로가 있어야 함"*

각 과정 카드에 상세 페이지로 가는 링크를 **미리 배치**합니다. 상세 페이지 자체는 이번 범위 밖입니다 (§7 참조).

```text
/education/programs/[slug]
  ai-tools · vibe-coding · web-app · automation
```

상세 페이지가 준비되기 전까지의 처리는 §7에서 정합니다.

### 5.3 지식 공유 커뮤니티 클럽 / 바이브데이즈 `#program-club`

**섹션이 아니라 모달 진입점입니다.** ver2의 독립 VIBEDAYS CLUB 섹션(§11)은 제거하고, 이 블록의 카드를 클릭하면 모달이 열립니다.

카드 표면:

```text
지식 공유 커뮤니티 클럽 / VIBEDAYS

혼자서는 어려웠던 AI 학습,
실험부터 피드백까지의 선순환을 매월 경험하세요.

[자세히 보기]
```
