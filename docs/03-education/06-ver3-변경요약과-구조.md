## 1. ver2 → ver3 변경 요약

가장 큰 변경은 **프로그램 분류 체계**입니다. ver2의 평면 6개 프로그램을 3분류 체계로 재편합니다.

| | ver2 | ver3 (IA 기준) |
|---|---|---|
| 프로그램 구조 | 평면 6개 | **3분류** + 정규 클래스 하위 4과정 |
| 섹션 수 | 14개 (Header/Footer 제외) | **8개** |
| VIBEDAYS | 독립 섹션 | **모달** |
| 통계바 | 없음 | **신설** |
| 지난 프로그램 | 없음 (교육 사례로 존재) | **신설** (실제 사례 이미지) |
| 후기 | 일반 인용 카드 | **별점 + 리뷰형** |
| AI Prototype Lab | 대표 프로그램 6개 중 하나 | **완전 폐지** |

### 3분류 체계

```text
01. 조직·기업 맞춤 교육
02. 정규 클래스          (하위 4과정)
03. 지식 공유 커뮤니티 클럽 / 바이브데이즈
```

이 3분류는 홈(핵심 비즈니스·포트폴리오 필터·Contact 세부 유형)과 Education 페이지(소개·프로그램 정보)에 **동일한 이름으로 반복 적용**됩니다. 페이지마다 다른 명칭을 쓰지 않습니다.

### ver2 프로그램 → ver3 매핑

| ver2 | ver3 |
|---|---|
| AI 활용 입문 | 정규 클래스 › **AI 활용**으로 통합 |
| AI 업무 활용 | 정규 클래스 › **AI 활용**으로 통합 |
| Vibe Coding | 정규 클래스 › **Vibe Coding** |
| AI 업무 자동화 | 정규 클래스 › **업무 자동화** |
| AI Prototype Lab | **폐지** |
| 기업 맞춤형 교육 | **조직·기업 맞춤 교육** |
| — | 정규 클래스 › **웹·앱 제작** (신규) |

## 2. 전체 페이지 구조

```text
01. Header (고정 네비게이션)
02. KPOPSOFT 교육프로그램 소개   ← Hero 겸 3분류 소개
03. 통계바
04. 전문 강사진 소개
05. 교육 프로그램 정보           ← 3분류 상세 + 상세 페이지 진입 경로
06. 지난 프로그램
07. 후기
08. FAQ
09. CONTACT
10. Footer
```

### ver2에서 제거하는 섹션

```text
방문 목적 선택 (visit-purpose)
교육 결과물   (edu-outputs)
교육 방식     (how-we-learn)
기업 맞춤형 교육 (org-training)   → 05 프로그램 정보로 흡수
교육 진행 프로세스 (edu-process)
개인/기업 CTA 스플릿 (cta-split)  → 09 CONTACT로 통합
```

컴포넌트 파일은 **삭제하지 않고 페이지에서 import만 끊습니다** (홈 ver2 개편과 동일한 방식). 되돌리기 쉽고 diff가 작습니다.
