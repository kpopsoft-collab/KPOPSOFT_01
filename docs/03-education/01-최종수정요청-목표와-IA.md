## 1. 작업 목표

현재 KPOPSOFT 교육 페이지의 브랜드 아이덴티티를 유지하면서 정보 구조, 레이아웃과 인터랙션을 개선해주세요.

### 반드시 유지할 요소

- KPOPSOFT 로고와 브랜드 톤
- 크림색 배경
- Software Blue, AI Solutions Red, Education Green 컬러 체계
- 파란 원, 빨간 스파크, 초록 물결 그래픽
- 현재 타이포그래피와 버튼 스타일
- 실제 교육 현장 사진
- 친근하지만 전문적인 인상

### 레이아웃 및 인터랙션 참고 사이트

https://www.bevel.health/

Bevel의 디자인을 복제하지 말고 다음 원리만 참고해주세요.

- 큰 제목과 짧은 설명 중심의 정보 위계
- 넓은 여백과 명확한 스크롤 리듬
- 큰 라운드형 섹션 컨테이너
- 실제 사용 장면 중심의 이미지
- 스크롤에 따라 콘텐츠가 하나씩 이해되는 전개
- 프로그램별 몰입형 레이아웃
- 가로로 이어지는 사례와 후기
- 절제된 스크롤 및 Hover 인터랙션

최종 방향:

> KPOPSOFT답게 보이지만, Bevel처럼 부드럽고 몰입감 있게 작동하는 교육 페이지

## 2. 최종 IA

~~~text
교육 메인 페이지
├─ 공통 고정 내비게이션
├─ 히어로
│  ├─ 교육 핵심 메시지
│  ├─ 프로그램 보기
│  └─ 교육 문의
├─ 교육 목적 선택
│  ├─ AI 입문
│  ├─ 실무 활용
│  └─ 기업·조직 교육
├─ 교육 성과
│  ├─ 누적 수료생
│  ├─ 운영 프로그램
│  ├─ 교육 만족도
│  └─ 교육 및 워크숍 실적
├─ 프로그램
│  ├─ 조직·기업 맞춤 교육 → 기업교육 상세 페이지
│  ├─ 정규 교육 과정 → 프로그램 상세 페이지
│  └─ 바이브데이즈 클럽 → 상세 모달
├─ 교육 사례 및 결과물
│  ├─ 지난 프로그램
│  ├─ 기업교육 사례
│  ├─ 정규 교육 사례
│  ├─ 바이브데이즈 클럽 활동
│  ├─ 바이브데이즈 세미나
│  └─ 수강생 프로젝트 및 결과물
├─ 전문 강사진
├─ 수강 후기
├─ 자주 묻는 질문
├─ 교육 문의
└─ 공통 푸터
~~~

### 최종 섹션 순서

1. 공통 고정 내비게이션
2. 히어로
3. 교육 목적 선택
4. 교육 성과
5. 프로그램
6. 교육 사례 및 결과물
7. 전문 강사진
8. 수강 후기
9. 자주 묻는 질문
10. 교육 문의
11. 공통 푸터

기존의 독립된 교육 방식, 기업·조직 맞춤 교육, 바이브데이즈 클럽 섹션은 삭제해주세요.

- 교육 방식은 각 프로그램 상세 페이지에서 설명
- 기업·조직 맞춤 교육은 프로그램 카드 클릭 후 상세 페이지에서 설명
- 바이브데이즈 클럽은 프로그램 영역에 포함하고 클릭 시 상세 모달 제공
