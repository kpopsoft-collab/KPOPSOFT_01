# KPOPSOFT 홈 메인 추가 수정 요청

현재 홈 메인의 전체적인 디자인 스타일과 섹션 구성은 유지하되, 아래 네 개 영역을 중심으로 수정해주세요.

히어로 영역은 이번 작업에서 수정하지 않습니다.

---

## 1. 프로젝트 사례 영역 강화

### 현재 문제

프로젝트 사례가 KPOPSOFT의 실제 제작 역량을 증명하는 핵심 콘텐츠인데, 현재는 카드 내부 이미지와 정보가 작아 실제 결과물이 충분히 강조되지 않습니다.

### 수정 방향

- 프로젝트 이미지 영역을 현재보다 약 1.3~1.5배 확대해주세요.
- 카드 전체 높이도 이미지 확대에 맞춰 조정해주세요.
- 프로젝트의 실제 웹·앱·관리자 화면을 가장 먼저 인식할 수 있게 구성해주세요.
- 카드 내부 텍스트의 정보 위계를 명확하게 정리해주세요.
- 프로젝트명과 핵심 제작 범위가 빠르게 읽히도록 해주세요.
- 카드 하단의 상세 보기 버튼 또는 화살표 인터랙션을 강화해주세요.

### 카드 정보 구조

1. 프로젝트 카테고리
2. 실제 프로젝트명
3. 핵심 제작 내용
4. 프로젝트 결과 화면
5. 상세 사례 보기

### 레이아웃 제안

단순한 동일 크기 3열 카드보다 첫 번째 대표 프로젝트를 더 크게 보여주는 비대칭 레이아웃을 우선 검토해주세요.

예시:

- 첫 번째 프로젝트: 큰 대표 카드
- 두 번째·세 번째 프로젝트: 상대적으로 작은 보조 카드
- 다음 프로젝트는 가로 스크롤 또는 더 보기로 연결

프로젝트 이미지는 장식용 썸네일처럼 작게 사용하지 말고, 실제 제작 결과를 확인할 수 있는 수준으로 보여주세요.

---

## 2. 핵심 사업 영역의 우선순위 조정

### 현재 문제

Software, AI Solutions, Education 카드가 모두 같은 크기와 비중으로 표현되어 세 사업이 완전히 동등한 핵심 사업처럼 보입니다.

홈페이지에서는 Software와 AI Solutions를 중심 사업으로 강조하고, Education은 별도 교육 페이지로 연결되는 보조 사업 영역으로 표현해야 합니다.

### 수정 방향

- Software와 AI Solutions 카드를 중심으로 확대해주세요.
- Education은 상대적으로 작은 카드 또는 가로형 연결 배너로 변경해주세요.
- 기존의 브랜드 컬러와 심볼 체계는 유지해주세요.

### 브랜드 심볼

- Software: 파란 원
- AI Solutions: 빨간 스파크
- Education: 초록 물결

### 권장 레이아웃

#### 상단

Software와 AI Solutions를 각각 큰 카드로 배치합니다.

- Software: 전체 영역의 약 50%
- AI Solutions: 전체 영역의 약 50%

#### 하단

Education을 가로형 배너로 배치합니다.

배너 안에는 다음 내용을 포함해주세요.

- Education 초록 물결 심볼
- 실무에 AI를 적용하는 교육이라는 핵심 메시지
- 실제 교육 현장 이미지
- 교육 프로그램 보기 CTA

Education을 삭제하는 것은 아니며, KPOPSOFT의 전체 역량 중 하나로 유지하되 홈에서는 Software와 AI보다 낮은 시각적 우선순위를 적용합니다.

## 3. WHY KPOPSOFT 레이더 영역 강화

### 현재 문제

5축 레이더 구조의 개념은 좋지만, 현재 그래픽과 설명의 크기가 작아 KPOPSOFT만의 차별화된 역량 구조가 충분히 강조되지 않습니다.

### 수정 방향

- 레이더 그래픽을 현재보다 약 20~30% 확대해주세요.
- 그래픽과 오른쪽 설명 영역 사이의 관계를 더 명확하게 구성해주세요.
- 이 레이더는 실제 측정 데이터가 아닌 브랜드 역량 구조도이므로 점수, 퍼센트, 순위, 수치형 눈금은 추가하지 마세요.

### 5개 역량

1. Strategy
2. Design
3. Technology
4. AI
5. Education

### 인터랙션

레이더의 각 축 또는 오른쪽 항목에 마우스를 올리거나 클릭하면:

- 해당 축과 연결선이 브랜드 컬러로 강조됩니다.
- 대응하는 설명 카드가 활성화됩니다.
- 나머지 항목은 약간 흐려집니다.
- 활성화된 항목은 배경색 또는 테두리로 구분해주세요.

스크롤 진입 시 레이더 선이 자연스럽게 그려지는 모션을 적용할 수 있습니다.

모션은 과하게 튀지 않도록 짧고 절제된 방식으로 구현해주세요.

## 4. 프로젝트 프로세스 영역 개선

### 현재 문제

Understand → Design → Build → Launch → Operate 흐름이 지그재그 형태로 표현되어 있지만, 시선 이동 방향과 단계 순서가 즉시 이해되지 않습니다.

### 유지할 단계

1. Understand
2. Design
3. Build
4. Launch
5. Operate

### 수정 방향

- 각 단계의 숫자와 단계명을 더 명확하게 연결해주세요.
- 01부터 05까지의 진행 방향을 한눈에 이해할 수 있게 구성해주세요.
- 단계 사이의 연결선은 장식이 아니라 실제 진행 순서를 안내하도록 표현해주세요.
- 각 단계 설명의 글자 크기와 명암 대비를 높여주세요.

### 권장 레이아웃

데스크톱에서는 5단계를 수평 타임라인 형태로 구성해주세요.

각 단계는 다음 구조를 가집니다.

- 원형 단계 번호
- 영문 단계명
- 짧은 한글 설명
- 다음 단계로 이어지는 연결선

모바일에서는 수직 타임라인으로 전환해주세요.

### 인터랙션

- 스크롤 진입 시 01부터 05까지 연결선이 순서대로 이어집니다.
- 각 단계가 순차적으로 활성화됩니다.
- 애니메이션이 끝난 뒤에는 모든 단계가 동일한 명확도로 유지됩니다.
- 호버 시 해당 단계의 설명만 강조할 수 있습니다.

## 공통 디자인 원칙

- 현재 KPOPSOFT의 크림색 배경과 타이포그래피를 유지합니다.
- 파란 원, 빨간 스파크, 초록 물결의 브랜드 체계를 유지합니다.
- 새로운 장식 요소나 색상을 무분별하게 추가하지 않습니다.
- 큰 제목, 짧은 설명, 넓은 여백의 현재 방향을 유지합니다.
- 인터랙션은 콘텐츠 이해를 돕는 범위에서만 적용합니다.
- 모바일에서도 정보 순서와 CTA가 명확하게 유지되도록 반응형으로 구현해주세요.
