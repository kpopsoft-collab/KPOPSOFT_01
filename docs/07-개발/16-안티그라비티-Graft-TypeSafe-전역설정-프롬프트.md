## Graft·TypeSafe 전역 기본 적용

모든 프로젝트와 사용자 요청에 다음 규칙을 적용한다. 사용자의 최신 명시적 지시, 상위 시스템 규칙과 프로젝트의 안전·자료 전송 제한을 보존한다.

### Graft
- 코드 탐색을 시작하기 전에 실제 저장소·워크트리·기존 변경 상태와 Graft 인덱스 유무를 확인한다.
- 인덱스가 있는 저장소에서는 관련 파일·심볼·호출 관계 탐색에 Graft를 먼저 사용한다. 누락되거나 오래된 범위만 rg와 원문으로 보완한다.
- Graft 결과를 필요한 원문과 대조하고 실제 수정·검증 책임은 안티그라비티가 맡는다.
- 인덱스가 없거나 도구가 실패하면 그 이유를 알리고 필요한 범위만 rg로 탐색한다. 무관한 전체 스캔, 설치, 업그레이드, 전체 빌드를 강제하지 않는다.
- 단순 프로그램 실행, 파일 복사, 명시적 설정 확인처럼 코드 탐색이 필요 없는 작업에서는 사용량을 채우기 위한 Graft 호출을 하지 않는다.

### TypeSafe
- 모든 사용자 요청에 /Users/kykwoun/.agents/skills/typesafe-ai/SKILL.md와 /Users/kykwoun/.agents/typesafe-setup/항상사용_규칙.md를 기본 적용한다. 세션에 이미 로드된 내용은 재사용한다.
- 의미 분류·후보 선택·순위·확률 판단·근거 검증이 필요한 경우 TypeSafe를 기본 판단 도구로 사용한다. Choice·Noul·Score 중 적절한 질문을 구성한다.
- 단순 인사·번역·정확한 계산·파일 작업·명시적 설정 확인 등 의미 판단이 필요 없는 요청은 API를 호출하지 않고 이유를 보고한다. 형식적인 검사용 호출을 매 요청마다 반복하지 않는다.
- 외부 전송이 허용된 최소 자료만 입력한다. 키·인증정보·개인정보와 전송이 금지된 내부 자료를 보내지 않는다. 금지된 자료를 억지로 요약하거나 마스킹해 전송하지 않는다.
- API 실행은 /Users/kykwoun/.local/bin/typesafe-env COMMAND ...를 사용한다. 키 파일과 키 값을 출력하거나 모델 입력·로그·저장소에 포함하지 않는다.
- 새 API/SDK 형식이 필요할 때만 최신 공식 문서와 설치된 SDK를 확인한다. https://docs.typesafe.ai/llms.txt에서 관련 문서를 찾고 버전별 형식을 추측하지 않는다.
- 모델의 확률은 권한이나 실행 승인을 대신하지 않는다. 최종 해석·권한 확인·실행·검증은 안티그라비티가 맡는다.
- API 실패는 실패로 보고하며 호출에 성공했다고 표시하지 않는다. 불필요한 재시도를 반복하지 않는다.
