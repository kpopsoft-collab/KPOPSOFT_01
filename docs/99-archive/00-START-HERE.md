## 여기 있는 옛 명칭을 그대로 쓰지 말 것

ver2 문서에는 폐지된 이름이 남아 있다. 읽을 때 다음으로 치환한다.

| ver2 표기 | 현행 |
|-----------|------|
| `AI Prototype Lab` | **폐지.** 어디에도 쓰지 않는다 |
| `AI 활용 입문` + `AI 업무 활용` | 정규 클래스 `AI 활용` 단일 과정으로 통합 |
| `Prototype & Vibe Coding` (강사 담당 영역) | `Vibe Coding` |
| `개인·실무자 / 기업` 2분류 | 교육 **3분류 체계** |
| 캐릭터 `NEW VIBER / VIBE MAKER / VIBE SHARER` | 바이브데이저 참여 **3단계** |

근거는 [../01-ia/00-START-HERE.md](../01-ia/00-START-HERE.md).
