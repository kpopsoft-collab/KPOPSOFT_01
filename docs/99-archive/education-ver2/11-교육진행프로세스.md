## Title

```text
기업과 참여자의 목표에 맞춰
교육을 설계합니다.
```

## 단계

### 01. Discover

```text
교육 대상과 현재 활용 수준,
해결해야 할 업무 과제를 파악합니다.
```

### 02. Design

```text
목표, 시간, 인원에 맞춰
교육 과정과 실습 과제를 설계합니다.
```

### 03. Practice

```text
실제 업무와 도구를 중심으로
강의와 실습을 진행합니다.
```

### 04. Build

```text
교육 과정에서 직접 사용할 수 있는
결과물과 템플릿을 제작합니다.
```

### 05. Apply

```text
교육 이후 업무에 적용할 방법과
다음 실행 과제를 정리합니다.
```
