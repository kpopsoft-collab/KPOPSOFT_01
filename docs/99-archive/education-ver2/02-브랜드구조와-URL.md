### 3.1 메인 브랜드

```text
KPOPSOFT EDUCATION
```

Education 페이지의 신뢰와 전문성은 KPOPSOFT가 담당합니다.

다음 영역에서는 KPOPSOFT를 우선적으로 노출합니다.

- Hero
- 기업 맞춤형 교육
- 교육 사례
- 강사진
- FAQ
- 상담 및 신청
- Footer

### 3.2 보조 아이덴티티

```text
VIBEDAYS CLUB
```

VIBEDAYS CLUB은 KPOPSOFT의 실습형 교육과 커뮤니티 문화를 표현하는 보조 아이덴티티입니다.

페이지 첫 화면에서 KPOPSOFT와 VIBEDAYS를 같은 비중으로 노출하지 마세요.

방문자가 KPOPSOFT Education의 프로그램과 방향을 먼저 이해한 뒤 페이지 중간에서 VIBEDAYS CLUB을 소개합니다.

추천 소개 문구:

```text
VIBEDAYS CLUB

서로 다른 경험과 수준을 가진 사람들이
배우고, 만들고, 자신의 결과를 나누는
KPOPSOFT의 실습형 러닝 커뮤니티입니다.
```

VIBEDAYS는 별도 회사나 별도 교육기관처럼 보이지 않아야 합니다.

## 4. 페이지 URL 및 확장 구조

### 기본 URL

```text
/education
```

### 향후 상세 페이지

```text
/education/[slug]
```

예시:

```text
/education/ai-intro
/education/ai-work
/education/vibe-coding
/education/ai-prototype-lab
/education/ai-automation
```

1차 개발에서는 상세 페이지를 구현하지 않아도 되지만, 프로그램 데이터에 `slug`, 상세 콘텐츠, SEO 필드를 준비해 주세요.
