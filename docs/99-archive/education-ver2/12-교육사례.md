## 15. SECTION 09 — 교육 사례

### Eyebrow

```text
EDUCATION CASES
```

### Title

```text
실제 업무 문제를
교육으로 함께 해결했습니다.
```

### 사례 카드 필드

- 사례명
- 기업 또는 산업군
- 교육 대상
- 참여 인원
- 교육 기간
- 교육 목표
- 주요 과제
- 교육 방식
- 교육 결과물
- 성과
- 대표 이미지
- 현장 이미지
- 결과물 이미지
- 상세 갤러리

### 예시 1

```text
제조기업 AI 업무 자동화 워크숍

대상
운영 및 관리 실무자

인원
30명

형태
6시간 실습형 워크숍

주요 과제
반복 보고서 작성 및 데이터 정리 자동화

결과물
부서별 AI 업무 템플릿과 자동화 흐름
```

### 예시 2

```text
스타트업 Vibe Coding 과정

대상
기획자 및 디자이너

인원
15명

형태
4주 프로젝트형 과정

주요 과제
사내 업무 도구 제작

결과물
작동 가능한 웹 기반 업무 도구
```

실제 사례가 없거나 공개 가능한 사례가 부족한 경우 Admin에서 전체 섹션을 숨길 수 있어야 합니다.

샘플 데이터와 실제 데이터는 코드와 데이터 구조상 명확히 구분합니다.

### 사례 이미지 구조 A — 이미지 상단형

```text
┌──────────────────────────────┐
│        교육 현장 이미지          │
├──────────────────────────────┤
│ 제조기업                      │
│ AI 업무 자동화 워크숍            │
│                              │
│ 운영·관리 실무자 30명             │
│ 6시간 실습형 워크숍               │
│                              │
│ 부서별 AI 업무 템플릿 완성         │
└──────────────────────────────┘
```

### 사례 이미지 구조 B — 가로 리스트형

```text
┌──────────────┬──────────────────────────┐
│              │ 제조기업                  │
│ 사례 이미지   │ AI 업무 자동화 워크숍       │
│              │                          │
│              │ 운영·관리 실무자 30명        │
│              │ 6시간 · 오프라인            │
│              │                          │
│              │ 부서별 자동화 템플릿 제작     │
└──────────────┴──────────────────────────┘
```

Desktop에서는 가로 리스트형을 사용할 수 있고 Mobile에서는 이미지 상단형으로 전환합니다.

### 이미지가 여러 장인 경우

- 대표 이미지 1장 + `+3` 표시
- 대표 이미지 1장 + 보조 이미지 2장
- 대표 이미지 1장 + 상세 보기에서 전체 갤러리
- 큰 이미지와 작은 이미지의 Editorial Grid

자동 재생 Carousel은 사용하지 않습니다.
