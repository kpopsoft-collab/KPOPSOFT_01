## Eyebrow

```text
LEARNING OUTPUTS
```

## Title

```text
수강생이 직접 만든
작동하는 결과입니다.
```

## Description

```text
교육은 설명을 듣는 것으로 끝나지 않습니다.
자신의 업무와 아이디어를 바탕으로
직접 사용할 수 있는 결과물을 완성합니다.
```

## 결과물 예시

### 반복 보고서 자동화

```text
AI Workflow

업무 데이터를 입력하면
보고서 초안을 자동 생성하는 도구
```

### 서비스 랜딩페이지

```text
Vibe Coding

AI와 함께 기획하고 제작한
반응형 웹페이지
```

### 신규 서비스 프로토타입

```text
AI Prototype Lab

아이디어 검증을 위한
작동 가능한 웹 프로토타입
```

### 사내 업무 대시보드

```text
Web & AI

운영 데이터를 한 화면에서 확인하는
내부 업무 도구
```

## 결과물 카드 구조

```text
┌─────────────────────────────────────┐
│                                     │
│          결과물 화면 이미지             │
│                                     │
├─────────────────────────────────────┤
│ VIBE CODING                         │
│ 서비스 랜딩페이지                     │
│ AI와 함께 제작한 반응형 웹페이지         │
└─────────────────────────────────────┘
```

## 레이아웃

Desktop:

- 첫 번째 대표 결과물은 큰 카드
- 나머지는 작은 카드 2~3개
- 비대칭 Editorial Grid 가능

```text
┌──────────────────────┬──────────────┐
│                      │   결과물 02   │
│      결과물 01        ├──────────────┤
│      큰 이미지        │   결과물 03   │
│                      │              │
└──────────────────────┴──────────────┘
```

Mobile:

- 한 열
- 이미지 먼저, 설명 아래
- 기본 구조에서 가로 스크롤 사용하지 않음

## 이미지 확대

- 클릭 시 확대 모달
- Escape 키로 닫기
- 바깥 영역 클릭으로 닫기
- 키보드 탐색 지원
- Caption 표시 가능
- 포커스 트랩 적용
