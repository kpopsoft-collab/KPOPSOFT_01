## 프로그램 카드 필수 정보

각 카드에는 다음 정보를 표시합니다.

- 대표 이미지
- 감성 라벨
- 프로그램명
- 한 줄 설명
- 추천 대상
- 난이도
- 교육 방식
- 모집 상태
- 상세 보기 또는 문의 버튼

## 이미지 원칙

추상적인 AI 이미지보다 실제 교육 결과물을 사용합니다.

- AI 활용 입문: AI 도구 실습 화면
- AI 업무 활용: 문서, 조사, 콘텐츠 결과 화면
- Vibe Coding: 수강생이 만든 웹 화면
- AI Prototype Lab: 작동 가능한 프로토타입
- AI 업무 자동화: 자동화 Workflow 또는 대시보드
- 기업 맞춤형 교육: 실제 워크숍 사진

이미지 영역 요구사항:

- 카드 상단 전체 너비
- 기본 비율 `4:3`
- `object-fit: cover`
- 모든 카드 동일 비율 유지
- 이미지 위에 감성 라벨과 모집 상태 오버레이 가능
- 과도한 Gradient overlay 금지
- 이미지가 없으면 KPOPSOFT 브랜드 Placeholder 사용
- 모든 이미지에 alt 필수

Desktop Hover:

- 이미지 1.02~1.04 확대
- 제목 또는 화살표 미세 이동
- 큰 그림자나 과도한 3D 효과 금지
