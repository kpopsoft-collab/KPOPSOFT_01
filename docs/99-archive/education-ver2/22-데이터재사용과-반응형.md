프로그램, 강사진, 후기, 사례 등의 데이터를 페이지마다 중복 등록하지 않습니다.

각 콘텐츠는 단일 데이터로 관리하고 노출 옵션으로 제어합니다.

예:

```ts
isPublished
isFeatured
showOnEducation
displayOrder
```

프로그램과 강사진은 관계형 또는 참조 방식으로 연결합니다.

```text
Program ↔ Instructor
```

후기는 관련 프로그램 또는 교육 사례와 연결할 수 있어야 합니다.

기존 데이터베이스 구조와 ORM을 먼저 분석하고 불필요한 별도 시스템을 만들지 않습니다.

## 29. 반응형 요구사항

모바일 우선으로 구현합니다.

### Desktop

- 콘텐츠 최대 너비 약 1200~1360px
- 프로그램 카드 3열
- 방문 목적 카드 2열
- 강사진 3열
- 교육 결과물 비대칭 그리드
- 기업 교육 영역 2열
- FAQ 최대 너비 약 900~1000px
- 교육 사례는 가로 리스트형 사용 가능

### Tablet

- 프로그램 카드 2열
- 강사진 2열
- 이미지 비율 유지
- 타이포그래피와 여백 축소

### Mobile

- 모든 주요 콘텐츠 1열
- 좌우 여백 약 20px
- 버튼 최소 높이 48px
- 가로 스크롤 방지
- 프로그램 카드 세로 배치
- 긴 제목 자연스럽게 줄바꿈
- FAQ 질문 전체 영역 탭 가능
- Header 모바일 메뉴 전환
- 교육 사례는 이미지 상단형 카드로 전환
- 이미지와 텍스트 순서를 정보 이해에 맞게 재배치
