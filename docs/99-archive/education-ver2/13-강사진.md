## Eyebrow

```text
INSTRUCTORS
```

## Title

```text
현업에서 직접 만들고
적용해 본 전문가가 함께합니다.
```

## Description

```text
소프트웨어 개발, AI 자동화,
디지털 프로덕트와 프로토타입 제작 경험을 바탕으로
실제 프로젝트 중심의 교육을 진행합니다.
```

## 강사진 카드 필드

- 프로필 이미지
- 이름
- 역할
- 한 줄 소개
- 대표 문구
- 전문 분야
- 주요 경력
- 담당 프로그램
- 공개 여부
- 노출 순서

## 예시 문구

### Software Lead

```text
좋은 소프트웨어는 설명이 필요 없습니다.
그냥 작동합니다.

Software Development
Digital Product
Web & App
Internal Tools
```

### AI Solutions

```text
AI는 도구입니다.
중요한 건 업무에 어떻게 녹이느냐입니다.

AI Automation
AI Workflow
AI 활용
사내 AI Tool
```

### Prototype & Vibe Coding

```text
완벽한 기획보다 빠른 프로토타입이
더 많은 것을 알려줍니다.

Prototype Development
Vibe Coding
AI Prototype
Digital Product
```

모든 프로필 사진은 같은 비율과 유사한 배경 및 크롭 스타일을 사용합니다.
