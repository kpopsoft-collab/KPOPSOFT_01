## 9. SECTION 03 — 대표 교육 프로그램

### Eyebrow

```text
PROGRAMS
```

### Title

```text
현재 수준과 목표에 맞는
프로그램을 선택하세요.
```

### Description

```text
AI를 처음 활용하는 단계부터,
직접 서비스와 업무 도구를 제작하는 과정까지
실습 중심으로 구성했습니다.
```

### 대표 프로그램 6개

#### 9.1 AI 활용 입문

감성 라벨:

```text
START DAY
```

설명:

```text
생성형 AI의 기본 개념과 주요 도구를 이해하고
업무에 활용하기 위한 기초를 익힙니다.
```

추천 대상:

```text
AI를 처음 접하는 실무자
```

난이도:

```text
입문
```

#### 9.2 AI 업무 활용

감성 라벨:

```text
WORK DAY
```

설명:

```text
문서 작성, 조사, 기획, 콘텐츠 제작과 같은
실제 업무에 AI를 적용합니다.
```

추천 대상:

```text
업무 생산성을 높이고 싶은 실무자
```

난이도:

```text
입문 · 실무
```

#### 9.3 Vibe Coding

감성 라벨:

```text
BUILD DAY
```

설명:

```text
개발 경험이 없어도 AI와 함께
웹 서비스와 업무 도구를 직접 제작합니다.
```

추천 대상:

```text
기획자, 디자이너, 비개발 실무자
```

난이도:

```text
입문 · 제작
```

#### 9.4 AI Prototype Lab

감성 라벨:

```text
PROTOTYPE DAY
```

설명:

```text
아이디어를 빠르게 작동하는 프로토타입으로 구현하고
실제 사용 가능성을 검증합니다.
```

추천 대상:

```text
신규 서비스와 아이디어를 검증하려는 팀
```

난이도:

```text
실무 · 프로젝트
```

#### 9.5 AI 업무 자동화

감성 라벨:

```text
FLOW DAY
```

설명:

```text
반복 업무를 분석하고 AI Workflow와
자동화 도구를 직접 구축합니다.
```

추천 대상:

```text
운영, 마케팅, 기획, 관리 실무자
```

난이도:

```text
실무 · 자동화
```

#### 9.6 기업 맞춤형 교육

감성 라벨:

```text
TEAM DAY
```

설명:

```text
조직의 직무, 수준, 업무 과제를 바탕으로
맞춤형 교육 과정을 설계합니다.
```

추천 대상:

```text
기업 및 기관
```

난이도:

```text
맞춤형
```
