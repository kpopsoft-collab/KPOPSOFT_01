Admin에 등록된 콘텐츠가 없을 때 레이아웃이 깨지지 않아야 합니다.

처리 대상:

- 프로그램 없음
- 교육 결과물 없음
- 사례 없음
- 강사진 없음
- 후기 없음
- FAQ 없음
- 이미지 로드 실패
- API 요청 실패

콘텐츠가 없는 경우 빈 카드를 표시하기보다 섹션 전체를 숨기는 것을 기본으로 합니다.

개발 환경의 예시 콘텐츠는 별도 mock data 파일로 분리합니다.

---

## 34. 1차 개발 범위

- `/education` 페이지
- 기존 Header와 Footer 재사용
- 반응형 레이아웃
- 개인·기업 방문 목적 선택
- 대표 프로그램 목록
- 프로그램 카드 이미지
- 교육 결과물 Editorial Grid
- VIBEDAYS CLUB
- 교육 방식
- 기업 맞춤형 교육
- 교육 프로세스
- 교육 사례 및 이미지 리스트
- 강사진
- 후기
- FAQ Accordion
- 개인 신청 및 기업 상담 CTA
- 기업 교육 문의 폼
- Admin 데이터 연동
- 섹션별 공개 여부
- 콘텐츠 정렬
- 이미지 공개 및 Blur 설정
- SEO와 접근성
- 빈 데이터 및 오류 상태

## 35. 2차 개발 범위

이번 작업에서 구현하지 않아도 되지만 확장 가능한 구조로 준비합니다.

- 프로그램 상세 페이지
- 모집 일정 관리
- 개인 교육 신청
- 신청자 관리
- 결제 또는 외부 신청 링크
- 상세 커리큘럼
- 프로그램별 FAQ
- 교육 사례 상세 페이지
- 수강생 결과물 갤러리
- 교육 자료 다운로드
- 수료증 또는 배지
- VIBEDAYS CLUB 커뮤니티 기능

## 36. 완료 조건

다음 조건을 만족하면 완료로 봅니다.

- `/education`으로 접근 가능
- 기존 KPOPSOFT 디자인 시스템 재사용
- 개인 프로그램과 기업 교육이 명확히 구분됨
- 대표 프로그램 6개가 이미지와 함께 표시됨
- 모든 프로그램 카드에 이미지 영역이 있음
- 교육 결과물이 실제 화면 이미지 중심 Grid로 표시됨
- 교육 사례가 현장 또는 결과물 이미지와 함께 표시됨
- Desktop 가로 사례 리스트가 Mobile에서 이미지 상단형으로 전환됨
- 여러 이미지 등록 시 이미지 수 또는 갤러리 진입 방식 제공
- 이미지가 없어도 브랜드 Placeholder로 레이아웃 유지
- 모든 이미지에 alt 제공
- 이미지 확대 모달이 키보드와 Escape를 지원
- 이미지별 공개 여부와 Blur 설정을 Admin에서 관리
- VIBEDAYS CLUB이 KPOPSOFT의 보조 아이덴티티로 이해됨
- 캐릭터가 페이지를 과도하게 지배하지 않음
- 기업 맞춤형 교육과 상담 동선이 명확함
- 강사진이 실제 프로필 사진 중심으로 표시됨
- FAQ가 접근성 있는 Accordion으로 작동
- Admin에서 프로그램, 결과물, 사례, 강사진, 후기, FAQ 관리 가능
- 주요 섹션을 Admin에서 숨기거나 노출 가능
- Desktop, Tablet, Mobile 정상 동작
- 문의 폼 검증, 제출, 성공, 오류 상태 정상 작동
- SEO metadata와 이미지 최적화 적용
- Layout Shift 방지
- 기존 홈페이지와 Admin 기능이 깨지지 않음

## 37. 구현 전 분석 요청

바로 코드를 수정하지 말고 먼저 현재 프로젝트를 분석해 주세요.

다음 내용을 먼저 정리해서 보여 주세요.

1. 현재 기술 스택
2. 프로젝트 디렉터리 구조
3. 기존 페이지 라우팅 구조
4. 기존 Header와 Footer 위치
5. 기존 디자인 토큰 및 공통 컴포넌트
6. 기존 홈페이지의 Education 관련 콘텐츠 위치
7. 기존 Admin 구조
8. 기존 데이터베이스 또는 CMS 구조
9. 기존 문의 폼 처리 방식
10. 기존 이미지 업로드 및 최적화 방식
11. 재사용 가능한 컴포넌트
12. 새로 생성할 파일
13. 수정할 파일
14. 데이터 모델 변경안
15. 마이그레이션 필요 여부
16. 구현 순서
17. 기존 기능에 영향을 줄 수 있는 위험 요소

분석 결과를 먼저 제시한 후 구현을 시작해 주세요.

## 38. 최종 실행 요청

현재 KPOPSOFT 웹사이트 프로젝트 구조와 기존 코드를 먼저 분석한 뒤 위 기획서를 기준으로 `/education` 페이지를 구현해 주세요.

중요 요구사항:

1. 기존 Header, Footer, 버튼, 타이포그래피, 컬러 토큰, 레이아웃 시스템을 최대한 재사용합니다.
2. 새로운 디자인 시스템을 별도로 만들지 않습니다.
3. KPOPSOFT EDUCATION이 메인 브랜드이고 VIBEDAYS CLUB은 보조 아이덴티티입니다.
4. 방문자가 VIBEDAYS를 별도 회사나 교육기관으로 오해하지 않도록 합니다.
5. 프로그램 설명보다 실제 교육 사진과 결과물 이미지를 시각적으로 강조합니다.
6. 개인 프로그램과 기업 맞춤형 교육의 진입 동선을 명확히 구분합니다.
7. VIBEDAYS 캐릭터는 Hero 보조 요소와 커뮤니티 영역에서만 적극적으로 활용합니다.
8. 기업 교육, 강사진, 사례, FAQ, 문의 영역에서는 전문성과 정보 전달을 우선합니다.
9. 모든 프로그램 카드에 이미지 영역을 포함합니다.
10. 교육 결과물은 비대칭 Editorial Grid로 구성합니다.
11. 교육 사례는 사진과 정보를 함께 읽는 가로 리스트 또는 이미지 상단 카드로 구성합니다.
12. 모든 콘텐츠를 동일한 썸네일 카드로 반복하지 않습니다.
13. Admin에서 페이지 문구, 이미지, 프로그램, 결과물, 사례, 강사진, 후기, FAQ를 관리할 수 있도록 합니다.
14. 동일한 데이터를 여러 위치에 중복 저장하지 않습니다.
15. 기존 데이터베이스, ORM, Form, Image, Animation 방식을 재사용합니다.
16. Desktop, Tablet, Mobile 반응형으로 구현합니다.
17. 접근성, SEO, 이미지 최적화, Loading, Empty, Error 상태를 포함합니다.
18. 실제 데이터가 없는 영역은 개발용 mock data로 분리합니다.
19. 기존 홈페이지와 Admin 기능을 삭제하거나 깨뜨리지 않습니다.
20. 관련 파일을 분석하고 변경 범위를 설명한 후 구현합니다.
