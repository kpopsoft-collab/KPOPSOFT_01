Software와 AI Solutions를 하나의 짧은 서비스 섹션으로 통합합니다.

### Eyebrow

```text
WHAT WE DO
```

### Title

```text
필요한 기술을
하나의 프로젝트로 연결합니다.
```

### Description

```text
기획서가 완성되지 않아도 괜찮습니다.

해결할 문제와 사용자, 업무 흐름을 함께 정리해
개발 가능한 제품과 솔루션으로 구체화합니다.
```

## Software

```text
웹 서비스
모바일 앱
기업용 소프트웨어
관리자 시스템
업무 관리 시스템
내부 운영 도구
MVP · Prototype
```

보조 문구:

```text
아이디어와 요구사항을 정리하고
기획부터 디자인, 개발까지 한 번에 구현합니다.
```

## AI Solutions

```text
AI 업무 자동화
AI 챗봇
콘텐츠 자동화
AI Workflow
사내 AI Tool
데이터 기반 업무 도구
AI Prototype
```

보조 문구:

```text
실험으로 끝나는 AI가 아니라
실제 조직에서 사용할 수 있는 업무 도구로 구현합니다.
```

### 비주얼

두 개의 큰 블록으로 구성하고 각각 실제 화면을 함께 보여줍니다.

- Software: 웹·앱·관리자 화면 모듈
- AI Solutions: 입력 → 처리 → 결과 Workflow

프로세스를 별도 섹션으로 추가하지 않습니다.

What We Do 하단에 다음 문구만 짧게 표시합니다.

```text
문제 정의 → 서비스 설계 → 디자인·개발 → 테스트
```
