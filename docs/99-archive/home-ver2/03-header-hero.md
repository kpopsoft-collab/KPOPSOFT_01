## SECTION 02. Hero

#### 콘텐츠

```text
SOFTWARE · AI SOLUTIONS

아이디어를
작동하는 기술로.

개발팀이 없어도, AI 도입이 막막해도 시작할 수 있습니다.

KPOPSOFT는 아이디어와 업무 문제를
웹·앱·내부 운영 도구와 AI 솔루션으로 구현합니다.

[프로젝트 의뢰하기]
```

#### 비주얼

추상적인 AI 이미지 대신 실제 프로젝트 화면을 사용합니다.

- 웹서비스 UI
- 모바일 앱 화면
- 관리자 대시보드
- AI 챗봇
- 자동화 Workflow
- 데스크톱과 모바일 화면 콜라주

권장 구조:

```text
좌측: 메시지와 CTA
우측: 실제 프로젝트 화면 3~4개
```

Hero 하단에 대표 프로젝트 이미지 일부가 보이도록 배치해 다음 Work 섹션으로 자연스럽게 연결합니다.
