## 8. 반응형 요구사항

### Desktop

- Hero 2열
- About + Numbers 압축형 레이아웃
- 대표 Work 대형 카드
- 보조 Work 2열
- What We Do 2열
- 최대 콘텐츠 너비 약 1200~1360px

### Tablet

- 대표 프로젝트는 전체 너비
- 보조 프로젝트 2열
- 서비스 블록 2열
- 이미지 비율 유지

### Mobile

- 모든 주요 섹션 1열
- Hero 이미지는 텍스트 아래
- 프로젝트 카드는 이미지 상단형
- 가로 프로젝트 카드는 세로 카드로 전환
- 좌우 여백 약 20px
- CTA 높이 최소 48px
- 카드 전체 터치 가능
- 가로 스크롤 방지

---

## 9. 디자인 방향

### 비주얼 비율

```text
실제 프로젝트 이미지 60%
텍스트와 브랜드 그래픽 40%
```

### 전체 무드

- 실제 화면 중심
- 넓은 여백
- 에디토리얼한 사례 배치
- 전문적이지만 지나치게 딱딱하지 않은 인상
- KPOPSOFT의 원·스파크·물결 그래픽 활용
- 기술을 과장하지 않는 태도
- 실제 구현 역량이 느껴지는 제작사 이미지

### 피해야 할 표현

- 모든 카드를 같은 형태로 반복
- 카드마다 CTA 버튼 반복
- 추상적인 AI 뇌·로봇 이미지
- 과도한 네온과 미래형 그래픽
- 의미 없는 3D 오브젝트
- 긴 텍스트 중심 섹션
- 홈에 교육 상세 콘텐츠 재노출
