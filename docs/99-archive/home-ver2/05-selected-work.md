홈에서 가장 중요한 섹션입니다.

### Eyebrow

```text
SELECTED WORK
```

### Title

```text
실제로 작동하는
제품과 도구를 만들었습니다.
```

### Description

```text
고객의 아이디어와 업무 문제를
실제로 사용할 수 있는 서비스와 업무 도구로 구현했습니다.
```

### 기본 구성

```text
대표 프로젝트 대형 카드 1개
보조 프로젝트 카드 2개
가로형 프로젝트 카드 1개
```

모든 카드를 같은 크기와 동일한 레이아웃으로 반복하지 않습니다.

### 대표 프로젝트 카드

- 실제 화면 이미지
- 산업군 또는 카테고리
- 프로젝트명
- 해결한 문제
- 제작 범위
- 핵심 성과
- 오른쪽 화살표
- 카드 전체 클릭

예시:

```text
INTERNAL TOOLS · AI AUTOMATION

주문 운영 자동화 어드민

분산된 주문과 출고 업무를
하나의 관리자 시스템으로 통합했습니다.

커머스 스타트업 · Web Admin · AI Automation ↗
```

### 보조 사례 예시

```text
고객 문의 AI 챗봇
핀테크 · AI Solutions

생산 데이터 대시보드 MVP
제조기업 · Digital Product

기업 교육 운영 플랫폼
교육기관 · Web Platform
```

### 카드 이미지 원칙

이미지는 카드 면적의 약 65~75%를 차지합니다.

- 웹서비스: 실제 전체 화면
- 앱: 디바이스 목업
- 관리자: 브라우저 대시보드
- AI 자동화: 입력 → 처리 → 결과
- Prototype: 주요 화면 콜라주

별도의 `사례 보기` 버튼은 반복하지 않습니다.

카드 전체를 클릭할 수 있게 하고 Hover 시 다음 정도만 적용합니다.

- 이미지 1.02~1.04 확대
- 화살표 또는 제목 미세 이동
- 과도한 그림자와 3D 효과 금지

프로젝트가 6개 이상 쌓이면 섹션 하단에만 다음 링크를 표시합니다.

```text
전체 프로젝트 보기 →
```
