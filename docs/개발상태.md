# 개발 상태

마지막 확인: 2026-07-31 · 날짜별 기록은 [작업로그.md](작업로그.md)

## ⚠️ 먼저 알아야 할 것 — 로컬과 배포가 DB를 공유합니다

Supabase 프로젝트가 하나라, **DB를 고치면 그 즉시 www.kpopsoft.com에 반영됩니다.**
반면 이미지·코드는 배포되어야 반영됩니다. 이 시차 때문에 2026-07-31 배포 사이트
이미지가 전부 깨진 적이 있습니다(작업로그 참조).

- 콘텐츠성 DB 변경(포트폴리오·문의 유형·통계 수치·강사진)은 **곧 배포**입니다.
- 배포 순서: `브랜치 배포 → 이미지 확인 → DB 반영`
- 포트폴리오 반영은 `scripts/apply-work-content.cjs` 사용 (이미지 미배포 시 자동 중단)

## 현재 상태

- Next.js 16 App Router 기반. 작업 브랜치는 `redesign/ver2`, 배포 브랜치는 `main`.
- **ver3 개편 진행 중** — 홈 7섹션 / 교육 8섹션. 기준 문서는 `IA_ver3_요약.md`와
  ver3 기획서 2종. ver2 문서는 참조용으로만 남아 있습니다.
- 공개 페이지 콘텐츠는 Supabase에서 읽고(`src/lib/public-content.ts`),
  `src/lib/site.ts`는 DB가 비었을 때의 **폴백 시드**입니다 — 시드만 고치면 화면은
  바뀌지 않습니다.
- 교육 페이지 콘텐츠는 아직 DB 스키마가 없어 `src/lib/education-content.ts` 정적 데이터입니다.
- Final CTA 문의 폼은 Server Action(`src/lib/inquiry-actions.ts`)으로 접수 + 이메일 알림(stub)합니다.

### 어드민 (docs/어드민기획.md 기준, DB 제외 선행 구축 §11.8)

- **P1 완료** — `/admin/login`(dev-bypass), `/admin` 대시보드, `/admin/inquiries` 목록·상세·상태/메모.
- **P2 완료** — `/admin/content/{work,insights,testimonials,experts,stats,inquiry-options}` 등록/수정/삭제/노출 토글. 강사·Work·Insights 커버 이미지 업로드(mock: data URL, 미리보기 동작). 문의 옵션은 유형→세부 유형(예시 문구) 2단 관리.
- **데이터/인증은 seam(어댑터)으로 분리**돼 mock으로 동작 — `lib/admin/data.ts`(문의), `lib/admin/content-data.ts`(콘텐츠), `lib/admin/inquiry-options.ts`(문의 옵션), `lib/admin/auth.ts`(dev-bypass). Supabase 연결 시 어댑터 구현만 교체(§11.8 체크리스트).
- 미구현: 관리자 초대 UI, ver3 반영(프로그램 3분류 2단 구조, 갤러리 `image_urls` 입력,
  후기 별점, 통계바). ver3 Admin 연동은 이번 범위 밖입니다.
- Supabase Auth/DB는 연결됨. Storage/이메일 발송은 아직 미연결.

## 검증

- `npm run lint` 통과
- `npm run build` 통과

Next.js 16 기본 Turbopack 빌드는 이 Codex 샌드박스에서 내부 포트 바인딩 제한 때문에 실패했습니다. `node_modules/next/dist/docs/01-app/03-api-reference/08-turbopack.md` 기준으로 Webpack 빌드가 공식 대안이라 `npm run build`는 `next build --webpack`을 사용하도록 맞춰두었습니다.

4. `redesign/ver2` 배포 → `scripts/apply-work-content.cjs --apply`로 포트폴리오 반영
5. 교육 프로그램 상세 페이지(`/education/programs/[slug]`) — 2차 범위
