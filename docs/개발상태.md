# 개발 상태

마지막 확인: 2026-08-02 · 날짜별 기록은 [작업로그.md](작업로그.md)

## ⚠️ 먼저 알아야 할 것 — 로컬과 배포가 DB를 공유합니다

Supabase 프로젝트가 하나라, **DB를 고치면 그 즉시 www.kpopsoft.com에 반영됩니다.**
반면 이미지·코드는 배포되어야 반영됩니다. 이 시차 때문에 2026-07-31 배포 사이트
이미지가 전부 깨진 적이 있습니다(작업로그 참조).

- 콘텐츠성 DB 변경(포트폴리오·문의 유형·통계 수치·강사진)은 **곧 배포**입니다.
- 배포 순서: `브랜치 배포 → 이미지 확인 → DB 반영`
- 포트폴리오 반영은 `scripts/apply-work-content.cjs` 사용 (이미지 미배포 시 자동 중단)

## 현재 상태

- Next.js 16 App Router 기반. 작업 브랜치는 `redesign/ver3`, 배포 브랜치는 `main`.
  둘은 같은 지점이며 ver3 개편 내용이 배포되어 있습니다.
- 공개 페이지 콘텐츠는 **전부 Supabase에서 읽습니다**(`src/lib/public-content.ts`).
  정적 데이터는 DB가 비었거나 조회가 실패할 때의 **폴백**입니다 — 폴백만 고치면 화면은
  바뀌지 않습니다. 홈·포트폴리오는 `src/lib/site.ts`, 교육은
  `src/lib/education-content.ts`, 핵심 비즈니스는 `src/lib/pillar-examples.ts`가
  각각 폴백입니다.
- 정적 데이터 → DB 반영은 `scripts/seed-education-ver3.cjs`,
  `scripts/seed-home-pillars.cjs`(둘 다 `--apply` 없이는 계획만 출력).
- `/insights`는 라우트·리더·시드를 모두 제거했습니다. DB 테이블과 글 3건은 남아 있습니다.
- Final CTA 문의 폼은 Server Action(`src/lib/inquiry-actions.ts`)으로 접수 + 이메일 알림(stub)합니다.

### 어드민

- **문의** — `/admin/login`, `/admin` 대시보드, `/admin/inquiries` 목록·상세·상태/메모.
- **콘텐츠** — 핵심 비즈니스(카드·사례 슬라이드), Work, 강사진, 홈 수치, 문의 옵션.
  Work는 갤러리 이미지·작업 범위·주요 기능·사용자 흐름·사이트 주소까지 편집합니다.
- **교육 8종** — 정규 클래스 / 조직·기업 교육(싱글턴) / 클럽 기수 / 클럽 참여 유형 /
  지난 프로그램(갤러리 포함) / 수강 후기 / FAQ / 교육 성과.
- 저장 시 공개 페이지 경로도 함께 `revalidatePath` 합니다 — 고친 것이 바로 보입니다.
- 화면 구조에 해당하는 값(도형 아이콘, 카드 클릭 동작, 카드 추가·삭제)은 의도적으로
  관리 대상에서 뺐습니다. 어드민에 두면 고칠 수 있는 것처럼 보이지만 실제로는 코드가
  함께 바뀌어야 합니다.
- 미구현: 관리자 초대 UI, 이메일 발송. Supabase Auth/DB/Storage는 연결돼 있습니다.
- **미검증**: 로그인 화면 뒤 실제 클릭 검증(저장·삭제)은 아직 못 했습니다
  (`ADMIN_DEV_BYPASS=false`).

## 검증

- `npx tsc --noEmit` 통과
- `npm run build` 통과
- `npm run lint`는 기존 에러 3건 때문에 실패합니다 — `src/components/layout/header.tsx`(1),
  `src/components/sections/education/vibedays-modal.tsx`(2). ver3 작업 이전부터 있던
  것으로 빌드에는 영향이 없습니다.

Next.js 16 기본 Turbopack 빌드는 이 Codex 샌드박스에서 내부 포트 바인딩 제한 때문에 실패했습니다. `node_modules/next/dist/docs/01-app/03-api-reference/08-turbopack.md` 기준으로 Webpack 빌드가 공식 대안이라 `npm run build`는 `next build --webpack`을 사용하도록 맞춰두었습니다.

## 다음 개발 우선순위

배포 전 반드시 처리할 항목과 미결 사항은 [작업로그.md](작업로그.md) 하단
"남은 결정 · 작업"에 정리되어 있습니다. 요약하면:

1. **어드민 클릭 검증** — 지난 프로그램 갤러리 추가·삭제, 클럽 기수 저장이 실제
   반영되는지 확인.
2. 정규 클래스 커리큘럼·이미지 컨펌, 후기 1건 보충
3. 교육 프로그램 상세 페이지(`/education/programs/[slug]`), 교육 사례 목록
   (`/education/cases`) — 둘 다 라우트만 열려 있는 빈 페이지
4. 실제 회사 이메일 연결, 남은 더미 수치 교체(클럽 참가자 120+ 등)
5. `/insights` DB 테이블·글 정리 여부 결정
