## A. 깨진 것이 실제로 고쳐졌나

| # | 확인 | 통과 기준 |
|---|------|----------|
| A1 | `ai-tools` 문서 높이 | **29,435px → 5,000px 미만** |
| A2 | `.course-html-shell` | DOM에 **0개** |
| A3 | 404 나던 `assets/*.jpg` 5건 | 콘솔 404 **0건** |
| A4 | `ai-tools` 커리큘럼 | 화면에 **보인다** (지금은 한 줄도 없다) |
| A5 | 상세 자료 링크 | `href`가 `*.supabase.co`, `target="_blank"`, `rel`에 `noopener` |

## B. 구조 — 4개 slug 전부

| # | 확인 |
|---|------|
| B1 | Breadcrumb이 있고 마지막 항목에 `aria-current="page"` |
| B2 | 요약 카드에 기간·난이도·일정·트랙이 **전부** 있다 |
| B3 | 일정이 없는 과정은 "상시 모집 · 문의 시 안내"가 나온다 (빈칸 아님) |
| B4 | 히어로에 메타 `dl`이 **중복으로 남아 있지 않다** |
| B5 | 커리큘럼이 **4개 slug 모두** 보인다 |
| B6 | 다른 과정 카드 3장이 있고, **자기 자신은 빠져 있다** |
| B7 | 대표 이미지가 본문 컬럼 폭과 어긋나지 않는다 |
| B8 | 없는 slug → 404, 목록 → 200 (기존 동작 유지) |

## C. 반응형 — 375 / 768 / 1440

| # | 확인 |
|---|------|
| C1 | 1440: 2단이고 요약 카드가 스크롤에 따라 **붙어 있다** |
| C2 | 768·375: 1단. 요약 카드는 히어로 아래 **한 번만** |
| C3 | 375: 하단 고정 CTA 바가 보이고 **마지막 섹션을 가리지 않는다** |
| C4 | 1440: 고정 바가 **없다** |
| C5 | 가로 스크롤 없음 — `scrollWidth <= clientWidth` |
| C6 | 모든 탭 타겟 **≥44px** |

## D. 디자인 시스템

| # | 확인 | 근거 |
|---|------|------|
| D1 | 그라데이션·글래스모피즘·과도한 그림자 없음 | [04-design-system/00](../../docs/04-design-system/00-START-HERE.md) |
| D2 | 새로 쓴 색·radius·간격이 전부 **등록된 토큰** | CLAUDE.md 컨벤션 |
| D3 | 한 화면에 원색 패널이 히어로·CTA 둘뿐 | [02-컬러시스템](../../docs/04-design-system/02-컬러시스템.md) |
| D4 | 본문 16px 이상 | WCAG AA |
| D5 | 포커스 링이 모든 링크·버튼에 보인다 | 같은 기준 |

## E. 백필 (4단계)

| # | 확인 |
|---|------|
| E1 | `--dry-run`이 대상 행과 계획을 정확히 출력한다 |
| E2 | `--apply` 후 `detail_bundle_path`가 `'<uuid>/'` 모양이고 CHECK를 통과한다 |
| E3 | `detail_html`이 비었다 |
| E4 | 동반 테이블의 **원본이 그대로 남아 있다** (되돌릴 수 있다) |
| E5 | Storage `education/<uuid>/index.html`이 200이고 `Content-Type: text/html` |
| E6 | 그 URL을 새 탭으로 열면 **슬라이드가 실제로 보인다** (JS·이미지 살아 있음) |

> E6에서 이미지가 여전히 깨지면 그것은 **업로드물이 단일 `.html`이라서**다.
> 그때는 zip으로 다시 올려야 한다 — 화면 버그가 아니라 콘텐츠 입력 문제다.
> 이 구분이 이번 작업의 핵심이므로 결과 문서에 반드시 적는다.

  **이 작업 뒤에 다시 보면 훨씬 쉬워진다.**
