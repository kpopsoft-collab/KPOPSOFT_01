# 검증 체크리스트

## 0. 먼저 알아둘 함정

**공개 페이지가 멀쩡해 보여도 DB 연동이 깨져 있을 수 있다.**
`getPublicRegularClasses()`는 조회에 실패하면 `src/lib/education-content.ts`의
정적 배열로 **조용히 폴백**한다. 즉 매핑을 빼먹어도 화면에는 기존 4개 과정이
정상 표시된다.

→ 검증할 때는 반드시 **어드민에서 값을 고치고 → 공개 화면에 그 값이 나오는지**로
확인한다. "화면이 나온다"는 통과 근거가 아니다.

## 1. 마이그레이션

- [ ] `information_schema.columns`에 컬럼 7개가 있다
- [ ] 기존 4행이 살아 있고 `schedule_type = 'multi'`, 날짜는 null
- [ ] 제약 위반이 실제로 막힌다
  ```sql
  -- 실패해야 정상
  update education_regular_classes set schedule_type='oneday',
    start_date='2026-09-01', end_date='2026-09-02' where slug='ai-tools';
  update education_regular_classes set schedule_type='multi',
    start_date='2026-09-10', end_date='2026-09-01' where slug='ai-tools';
  ```
- [ ] `mcp__supabase__get_advisors`에 새 경고가 없다

## 2. 어드민 폼 — 일정

- [ ] `/admin/content/education/regular-classes/new`에서 일정 유형이 기본 **다회차**
- [ ] **원데이** 선택 → 날짜 입력이 `강의일` 하나로 바뀐다 (종료일이 DOM에서 사라진다)
- [ ] **다회차** 선택 → `시작일`/`종료일` 두 개
- [ ] 원데이에 날짜를 넣고 → 다회차로 바꿔도 시작일이 남아 있다
- [ ] 다회차에서 종료일 < 시작일 → 저장 버튼 비활성 + 빨간 안내
- [ ] 날짜를 전부 비운 채 저장 → 성공
- [ ] 저장 후 `[id]` 페이지를 다시 열면 고른 유형과 날짜가 그대로 복원된다
- [ ] 원데이로 저장했다가 다회차로 바꿔 저장 → 종료일이 정상 반영
- [ ] 다회차 → 원데이로 바꿔 저장 → DB `end_date`가 **null**이 됐다 (남아 있으면 3단계 `normalize()` 누락)

## 3. 어드민 폼 — HTML 업로드

- [ ] `.html` 파일 선택 → 파일명이 화면에 뜬다
- [ ] `.png` / `.txt` 선택 → 한글 에러 메시지, 상태 변화 없음
- [ ] 1MB 초과 파일 → 한글 에러 메시지
- [ ] `제거` 누르고 저장 → DB `detail_html`, `detail_html_raw`, `detail_html_name`이 모두 비었다
- [ ] 저장 후 다시 열면 파일명이 남아 있다
- [ ] 아무것도 안 올린 기존 과정을 저장해도 기존 값이 안 지워진다

### 3-1. 정제 (필수)

아래 파일을 올려 저장한 뒤 **DB `detail_html` 컬럼을 직접 조회**한다.

```html
<h2>과정 소개</h2>
<p onclick="alert('xss')">클릭</p>
<script>alert('xss')</script>
<img src=x onerror="alert('xss')">
<iframe src="https://example.com"></iframe>
<a href="javascript:alert('xss')">링크</a>
<style>h2 { color: red }</style>
```

- [ ] `detail_html`에 `<script`가 없다
- [ ] `onclick` / `onerror` 속성이 없다
- [ ] `<iframe`이 없다
- [ ] `href="javascript:` 가 없다
- [ ] `<h2>과정 소개</h2>`와 `<p>클릭</p>`는 **남아 있다** (정제가 과하면 본문이 사라진다)
- [ ] `detail_html_raw`에는 **원본이 그대로** 있다
- [ ] `<style>` 처리 결과가 결정(§04 4단계)한 대로다 — 제거했거나 `.course-html`로 스코프됨

### 3-2. 우회 경로

- [ ] 브라우저 콘솔에서 서버 액션에 정제 안 된 HTML을 직접 넘겨도 `detail_html`에는
      정제본만 들어간다 (정제가 클라이언트에만 있으면 여기서 뚫린다)

## 4. 공개 화면

- [ ] 어드민에서 일정을 넣고 저장 → `/education` 정규 클래스 카드에 일정 표기가 뜬다
- [ ] 날짜 없는 과정 카드에는 일정 줄 자체가 없다 (빈 칸이나 `–`가 남지 않는다)
- [ ] 원데이 표기 형식이 [01-요구사항.md](01-요구사항.md) §2.4 표와 같다
- [ ] `2026-09-12`가 화면에 **9월 12일**로 나온다 (11일이면 타임존 버그)
- [ ] 비공개(`isPublished=false`) 과정은 공개 화면에 안 나온다

## 5. 회귀

- [ ] `npx tsc --noEmit` 통과
- [ ] `npm run build` 통과 / `npm run lint` 통과
- [ ] 기존 4개 과정을 아무것도 안 고치고 저장 → 모든 필드 그대로
- [ ] 교육 폼 다른 6종(클럽 기수/티어/지난 프로그램/후기/FAQ/성과)이 그대로 저장된다
      (`fields.tsx`·`FormActions`·`SupabaseRepo`를 건드렸다면 필수)
- [ ] `/education` 페이지에서 콘솔 에러 없음

## 6. 반응형·접근성 (docs/04-design-system/)

- [ ] 375 / 768 / 1440에서 일정 fieldset이 안 깨진다
- [ ] 라디오 탭 타겟 44px 이상, 키보드 화살표로 선택 이동
- [ ] 라디오 그룹에 `fieldset`+`legend`, 에러 메시지에 `role="alert"`
- [ ] 대비 WCAG AA
