## 3단계 — 목록 컴포넌트

새 폴더: `src/components/sections/education/programs/`

| 파일 | 역할 |

| `track-filter.tsx` (`"use client"`) | 칩 버튼 3개 |

### 트랙 필터

```tsx
const [track, setTrack] = useState<EduTrack | "all">("all");
const shown = track === "all" ? items : items.filter((c) => c.tracks.includes(track));
```

- 라벨은 `educationTrackLabel`(`content-types.ts`)과 **같은 문구**를 쓴다.
  어드민에서 고른 것과 화면 표기가 다르면 무엇을 고른 건지 알 수 없다.
  공개 쪽에도 같은 라벨이 있는지 확인하고, 없으면 한 곳으로 모은다
- 칩에 `aria-pressed`, 탭 타겟 44px
- 필터 결과 0건 → "해당 트랙 과정이 아직 없습니다" + 전체 보기 버튼
- URL 쿼리(`?track=beginner`) 동기화는 선택. 공유 링크가 필요해지면 그때

### 카드

```
┌─────────────────────────┐
│ [이미지 or 도형]         │
│ 01  ·  4주  ·  입문·중급 │
│ AI 활용                  │  ← name
│ AI 도구 마스터            │  ← subtitle
│ 설명 2줄 클램프           │
│ 2026년 9월 1일 – 10월 5일 │  ← 일정 (있을 때만, 백로그 01)
│ #AI 입문 #실무 활용       │
│ 자세히 보기 →             │
└─────────────────────────┘
```

- 카드 전체를 링크로 감싸되 내부에 중첩 링크를 두지 않는다
- `accent`로 상단 띠/도형 색 지정. 하드코딩 hex 금지, Tailwind 토큰 사용
- 그리드: `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`

## 4단계 — 상세 페이지 라우트

새 파일: `src/app/education/programs/[slug]/page.tsx`

```tsx
export const dynamic = "force-dynamic";

export async function generateMetadata(
  { params }: { params: Promise<{ slug: string }> },
): Promise<Metadata> {
  const { slug } = await params;
  const c = await getPublicRegularClass(slug);
  if (!c) return {};                       // notFound()는 페이지가 한다
  const title = c.seo.title || `${c.name} | KPOPSOFT Education`;
  const description = c.seo.description || c.description;
  return {
    title: { absolute: title },            // 루트 템플릿 "%s | KPOPSOFT" 중복 방지
    description,
    alternates: { canonical: `${route.educationPrograms}/${c.slug}` },
    openGraph: { type: "article", locale: "ko_KR", siteName: "KPOPSOFT",
                 url: `${route.educationPrograms}/${c.slug}`, title, description,
                 ...(c.image ? { images: [{ url: c.image.src, alt: c.image.alt }] } : {}) },
    twitter: { card: "summary_large_image", title, description },
  };
}

export default async function Page({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  const item = await getPublicRegularClass(slug);
  if (!item) notFound();
  // …
}
```

`params`가 Promise인 것에 주의(Next.js 15 App Router). 기존
`[id]/page.tsx`(어드민)가 같은 패턴이다.

`generateMetadata`와 페이지가 리더를 두 번 호출하지만 `force-dynamic`이라
같은 요청 안에서 처리된다. 신경 쓰이면 `React.cache`로 감싼다.

## 5단계 — 상세 페이지 컴포넌트

| 파일 | 역할 |
|---|---|
| `program-detail-hero.tsx` | 순번·이름·부제·설명 + 메타(기간/난이도/일정/트랙) |
| `curriculum-timeline.tsx` | `curriculum[]` 주차별 목록 |
| `course-html.tsx` | `detailHtml` 렌더 — **백로그 01 의존** |

### `course-html.tsx` — 주의

```tsx
/**
 * 어드민이 올린 과정 상세 HTML을 렌더한다.
 *
 * 여기 들어오는 값은 서버에서 sanitizeCourseHtml()을 통과한 것뿐이다
 * (backlogs/01-.../04-구현계획.md 4단계). 정제되지 않은 detailHtmlRaw 를
 * 이 컴포넌트에 넘기지 말 것 — 그 순간 저장형 XSS 경로가 된다.
 */
export function CourseHtml({ html }: { html: string }) {
  return (
    <div
      className="course-html …"
      dangerouslySetInnerHTML={{ __html: html }}
    />
  );
}
```

`.course-html` 하위 요소 기본 타이포(제목/문단/목록/표)를 CSS로 잡아 준다.
안 잡으면 Tailwind preflight 때문에 `<h2>`가 본문과 같은 크기로 나온다.

분기
```tsx
{item.detailHtml
  ? <CourseHtml html={item.detailHtml} />
  : <CurriculumTimeline items={item.curriculum} />}
```

## 6단계 — 선택 블록 (강사·후기·FAQ)

```tsx
const [experts, reviews, faqs] = await Promise.all([
  getPublicExperts(), getPublicEducationReviews(), getPublicEducationFaqs(),
]);
```

- 후기는 `program` 필드로 이 과정 것만 거른다. 정확히 매칭되는 게 없으면
  **섹션 자체를 뺀다** (다른 과정 후기를 끌어오지 않는다 — 읽는 사람이
  이 과정 후기로 오해한다)
- 강사·FAQ는 전체 공용이라 그대로 노출 가능
- 각 블록은 배열이 비면 렌더하지 않는다

`/education#inquiry`(문의 섹션 앵커)로 보낸다. 앵커 id는
