# 요구사항

## 1. 원문 요청

> `src/app/education/programs/page.tsx`
> - DB 연동
> - 목록페이지, 상세페이지 개발

## 2. 목록 페이지 — `/education/programs`

### 2.1 역할

`/education`의 프로그램 카드에서 `정규 교육과정 알아보기`를 누른 사람이 도착하는
곳. **정규 클래스 전체를 한눈에 보고 하나를 고르는 화면**이다.

`/education` 안에도 정규 클래스 목록이 이미 있다(`edu-programs` 섹션). 차이를
분명히 해야 두 화면이 서로를 대체하지 않는다.

| | `/education` 안 | `/education/programs` |
|---|---|---|
| 목적 | 교육 3분류 중 하나로 소개 | 정규 과정만 놓고 비교·선택 |
| 정보량 | 과정명 태그 정도 | 과정별 카드(설명·기간·난이도·일정·커리큘럼 요약) |
| 필터 | 없음 (목적 선택이 정렬만 바꿈) | **트랙 필터** (전체 / AI 입문 / 실무 활용) |
| 다음 행동 | 이 페이지로 이동 | 상세 페이지로 이동 |

`/work` 페이지가 홈 PROJECTS 섹션에 대해 하는 일과 같은 관계다
(`src/app/work/page.tsx` 주석 참고). **그 페이지를 구조 모델로 삼는다.**

### 2.2 구성

```
Header
├ 히어로        Eyebrow "PROGRAMS" + h1 + 리드 문단
├ 트랙 필터     전체 / AI 입문 / 실무 활용  (칩 버튼)
├ 과정 카드 목록  n개, sortOrder 순
│   └ 카드: 순번(01) · 과정명 · 부제 · 설명 · 이미지 · 기간 · 난이도
│           · 일정 표기(있으면) · 트랙 태그 · "자세히 보기"
├ 문의 CTA      기존 문의 섹션으로
Footer
```

- 카드 색은 `accent` 컬럼을 그대로 쓴다(브랜드 7색).
- 이미지는 `imageUrl`. 없으면 도형 플레이스홀더(docs/04-design-system/05-도형시스템.md 그래픽 언어).
- **`robots: { index: false }`를 제거한다** — 지금은 빈 페이지라 막아 뒀다.

### 2.3 빈 상태

공개된 과정이 0개면 "준비 중입니다" 안내 + 문의 CTA. 카드 영역만 사라지고
헤더·푸터·문의는 남는다.

## 3. 상세 페이지 — `/education/programs/[slug]`

### 3.1 라우팅

`education_regular_classes.slug`를 URL 세그먼트로 쓴다
(`ai-tools`, `vibe-coding`, `web-app`, `automation`).

- 없는 slug → `notFound()`
- 비공개(`is_published=false`) → `notFound()` (어드민 미리보기는 범위 밖)
- `generateStaticParams`는 쓰지 않는다 — 다른 공개 페이지와 같이
  `export const dynamic = "force-dynamic"`. 어드민 수정이 즉시 보여야 한다.

`detailHref` 컬럼과의 관계는 [00-START-HERE.md](00-START-HERE.md) D2 참고.

### 3.2 구성

```
Header
├ 히어로        순번 · 과정명 · 부제 · 설명 · accent 배경 도형
│               메타: 기간 / 난이도 / 일정 / 트랙
├ 대표 이미지    imageUrl + imageAlt + imageCaption (있을 때만)
├ 본문
│   ├ detail_html 이 있으면 → 정제된 HTML 렌더        ← 백로그 01 결과물
│   └ 없으면      → curriculum[] 기반 주차별 타임라인
├ 강사진(선택)   getPublicExperts() — 있으면
├ 후기(선택)     getPublicEducationReviews() 중 이 과정 것
├ FAQ(선택)      getPublicEducationFaqs()
├ 신청/문의 CTA  문의 섹션으로 (D4)
Footer
```

선택 블록은 **데이터가 있을 때만** 그린다. 빈 섹션 제목만 남으면 페이지가
미완성으로 보인다.

### 3.3 SEO

`seo_title` / `seo_description` 컬럼이 이미 있다. **반드시 쓴다** — 안 쓰면
어드민에 있는 입력란이 아무 일도 안 하는 칸이 된다.

```ts
export async function generateMetadata({ params }): Promise<Metadata> {
  // seoTitle 있으면 absolute, 없으면 `${name} | KPOPSOFT Education`
  // alternates.canonical = `/education/programs/${slug}`
  // openGraph: title/description/url, images는 imageUrl 있으면
}
```

없는 slug일 때 메타데이터에서 throw 하지 않는다 — `notFound()`가 뜨기 전에
빌드가 깨진다.

## 4. 비기능 요구

- **디자인**: `docs/04-design-system/` — flat color, 도형 시스템, radius 999 버튼,
  그라데이션·글래스모피즘 금지
- **반응형**: 375 / 768 / 1440. 목록 카드는 1 / 2 / 3열
- **접근성**: WCAG AA, 본문 16px 이상, 탭 타겟 44px, 필터 칩은 `aria-pressed`
- **컴포넌트화**: 화면 조각은 `src/components/sections/education/programs/*`에
  둔다(CLAUDE.md 컨벤션). 페이지 파일은 조립만 한다
- **토큰**: 하드코딩 hex/px 금지, Tailwind 테마 토큰 사용

## 5. 받아들임 기준

- [ ] `/education/programs`에 DB의 공개 정규 클래스가 전부 나온다
- [ ] 어드민에서 과정명을 고치면 새로고침으로 반영된다 (정적 폴백이 아니라 DB를 읽고 있다)
- [ ] 트랙 필터가 동작한다
- [ ] 카드의 `자세히 보기` → `/education/programs/[slug]` 이동
- [ ] 상세 페이지가 4개 과정 전부에서 정상 렌더
- [ ] 없는 slug → 404
- [ ] 비공개 과정 → 목록에 없고 직접 URL도 404
- [ ] `detail_html`이 있으면 그 본문이, 없으면 커리큘럼 타임라인이 나온다
- [ ] 상세 페이지 `<title>`이 `seo_title`을 따른다
- [ ] `/education` 카드 CTA가 이 페이지로 정상 연결된다
- [ ] `robots: noindex`가 제거됐다
