# 검증 체크리스트

## 0. 먼저 — "연동됐다"를 어떻게 확인하나

`getPublicRegularClasses()`는 조회 실패·빈 결과에서 **정적 4행으로 조용히
폴백**한다([02-현황분석.md](02-현황분석.md) §4). 그래서 DB를 전혀 안 읽어도
화면에는 AI 활용·Vibe Coding·웹앱·자동화 4개가 정상 표시된다.

**통과 판정 방법 — 아래를 실제로 해 본다.**

1. 어드민에서 `AI 활용` 과정명을 `AI 활용 (연동확인)`으로 바꿔 저장
2. `/education/programs` 새로고침 → **`(연동확인)`이 보여야 한다**
3. 어드민에서 새 과정을 하나 추가 → 목록에 5개가 나와야 한다
4. 확인 후 원상복구

2번에서 원래 이름이 그대로면 **정적 폴백을 보고 있는 것이다.** 연동 실패다.

## 1. 목록 페이지

- [ ] `/education/programs`가 200으로 뜬다
- [ ] §0의 연동 확인 4단계 통과
- [ ] 카드가 `sort_order` 순으로 나온다 (어드민에서 순서를 바꿔 확인)
- [ ] 비공개(`is_published=false`)로 바꾼 과정이 목록에서 사라진다
- [ ] 카드에 순번·과정명·부제·설명·기간·난이도가 나온다
- [ ] 이미지가 있는 과정은 이미지가, 없는 과정은 플레이스홀더가 나온다
      (깨진 이미지 아이콘이 아니다)
- [ ] `accent` 색이 과정마다 다르게 반영된다
- [ ] `metadata`에서 `robots: { index: false }`가 **제거됐다**
- [ ] `<title>`, `description`, canonical이 설정돼 있다

## 2. 트랙 필터

- [ ] 기본이 `전체`이고 모든 과정이 보인다
- [ ] `AI 입문` → `tracks`에 `beginner`가 든 과정만
- [ ] `실무 활용` → `practical`만
- [ ] 두 트랙을 다 가진 과정이 양쪽 모두에서 보인다
- [ ] 필터 라벨 문구가 어드민 체크박스 라벨(`AI 입문` / `실무 활용`)과 같다
- [ ] 결과 0건일 때 안내가 나오고 전체로 돌아갈 방법이 있다
- [ ] 칩에 `aria-pressed`가 있고 키보드로 조작된다

## 3. 상세 페이지

- [ ] 4개 과정 전부 `/education/programs/[slug]`가 200으로 뜬다
      (`ai-tools`, `vibe-coding`, `web-app`, `automation`)
- [ ] 목록 카드 `자세히 보기` → 해당 상세로 이동
- [ ] 없는 slug (`/education/programs/nope`) → **404**
- [ ] 비공개 과정의 slug로 직접 접근 → **404**
- [ ] 히어로에 이름·부제·설명·기간·난이도·트랙이 나온다
- [ ] `curriculum`이 주차별로 나온다
- [ ] 강사·후기·FAQ 블록이 **데이터가 있을 때만** 나온다
      (빈 배열인데 제목만 남지 않는다)
- [ ] 후기 블록에 **다른 과정 후기가 섞이지 않는다**
- [ ] 하단 CTA가 실제로 문의 섹션에 도달한다 (앵커가 살아 있다)

## 4. 상세 페이지 SEO

- [ ] `<title>`이 `seo_title` 값을 따른다 (어드민에서 바꿔 확인)
- [ ] `seo_title`이 비면 `${name} | KPOPSOFT Education`로 대체된다
- [ ] `%s | KPOPSOFT` 템플릿이 **중복으로 붙지 않는다** (`title: { absolute }`)
- [ ] canonical이 `/education/programs/[slug]`
- [ ] og:title / og:description / og:url이 채워진다
- [ ] 없는 slug에서 `generateMetadata`가 throw 하지 않는다 (404가 정상 렌더)

## 5. HTML 본문 (백로그 01 완료 시)

- [ ] `detail_html`이 있는 과정 → HTML 본문이 나온다
- [ ] `detail_html`이 빈 과정 → 커리큘럼 타임라인이 나온다
- [ ] 본문 안 `<h2>`/`<ul>`/`<table>`이 본문 텍스트와 구분되게 스타일링됐다
      (Tailwind preflight로 다 뭉개지지 않았다)
- [ ] `<script>`가 든 파일을 올려도 상세 페이지에서 실행되지 않는다
      (`detail_html`은 정제본이므로 애초에 없어야 한다)
- [ ] 올린 HTML의 스타일이 **헤더·푸터에 새지 않는다**

## 6. 진입점

- [ ] `/education` → 정규 과정 카드 `정규 교육과정 알아보기` → 이 페이지 도착
- [ ] `src/lib/site.ts`와 `edu-programs.tsx`의 "아직 빈 페이지" 주석이 갱신됐다
- [ ] 어드민에서 과정을 수정하면 `/education/programs`와 상세가 즉시 반영된다
      (`revalidatePath` 추가분 확인)

## 7. 반응형·접근성 (`docs/04-design-system/`)

playwright MCP로 확인한다.

- [ ] 375 / 768 / 1440에서 목록 그리드가 1 / 2 / 3열
- [ ] 상세 페이지에서 가로 스크롤이 생기지 않는다 (긴 표·코드 블록 포함)
- [ ] 본문 16px 이상, 탭 타겟 44px 이상
- [ ] 대비 WCAG AA
- [ ] `h1`이 페이지당 하나
- [ ] 이미지에 의미 있는 `alt` (장식이면 `alt=""`)
- [ ] 그라데이션·글래스모피즘이 없다 (`design-reviewer` 에이전트로 대조)

## 8. 회귀

- [ ] `npx tsc --noEmit` / `npm run build` / `npm run lint` 통과
- [ ] `/education` 페이지가 그대로 동작한다 (같은 리더를 공유한다)
- [ ] `/education/cases`는 여전히 빈 페이지로 남아 있다 (이번 범위 밖)
- [ ] 콘솔 에러 없음
